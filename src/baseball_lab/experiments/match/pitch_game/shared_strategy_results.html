통합 AI 전략 관찰

어떤 야구를 배웠나요?

공격과 투구 AI가 양쪽 역할의 경험을 함께 배웁니다. 팀은 연습을 위한 역할이며, 결과는 통합 AI의 선택과 변화로 읽습니다.

어떤 경험을 함께 배웠나요?

리그별 연습 기회를 고르게 배정하고, 각 리그 안에서 연도를 순환합니다. 경기 결과는 해당 리그·연도의 기록으로 추정합니다. 여러 리그를 MLB 평균으로 바꾸지 않습니다.

어떤 구종을 어느 쪽으로 선택했나요?

실제 추적 자료가 있는 구종·구속대·구역의 조합을 선택한 기록입니다. 아래는 학습 AI의 가상 투구 분포입니다.

분포를 읽는 방법

칸의 비율은 선택한 리그·구종의 투구 전체에서 해당 구역을 선택한 비중입니다. 존 밖의 공도 양 끝 구역에 포함합니다.

좌·우는 각 출처의 화면 방향입니다. MLB는 통과 좌표, KBO·NPB는 공개된 화면 좌표 규칙으로 나눴습니다. 타자의 몸쪽·바깥쪽이나 동일한 물리 좌표를 뜻하지 않습니다.

빈 칸은 해당 선택이 없었다는 뜻입니다. 좌표가 없는 원본은 이 코스 연구에 넣지 않으며 다른 리그의 좌표로 채우지 않습니다.

적음

같은 공, 같은 상황에서 달라진 선택

경험한 상황의 차이와 학습의 변화를 구별하려고, 학습 전후에 같은 상황을 제시했습니다.

주요 선택의 전후 확률

높은 선택 확률은 현재 정책의 선호입니다. 전역 최적 전략이나 실제 야구에서의 인과 효과가 입증됐다는 뜻은 아닙니다.

자료를 어떻게 골랐나요?

실제 구종·구속·위치와 투구 결과가 함께 있는 행만 코스 모델에 사용합니다. 원본과 제외 내역은 보존합니다. 아래는 교재 전체의 처리 내역이며 위의 학습 경험 횟수와 다릅니다.

KBO 추가 위치 자료는 2026년 롯데 참가 144경기의 양 팀 투구이며 리그 전체가 아닙니다. NPB는 공개 원본의 화면 위치와 제공 화면의 구종 정의를 대조했습니다. MLB 2026년과 이전 연도는 판정·좌표 관측 방식이 달라 연도별 환경을 유지합니다.

모형과 검증의 범위

구종·코스 선택은 관측된 패턴을 조건으로 결과를 추정합니다. 드문 상황은 같은 리그·연도의 기록으로 축소 추정합니다. 공을 원하는 곳에 항상 던지는 실제 제구 능력을 검증한 모델은 아닙니다.

당겨치기·밀어치기는 접촉 방향 기록을 사용한 목표 모델입니다. 타자의 실제 의도 기록은 없으므로, 헛스윙과 파울 확률은 일반 스윙과 공유합니다. 타석 방향이 없는 원본에서는 좌·중·우 목표로만 배웁니다.

경기 승리·패배만 학습 보상입니다. 자료는 날짜 순서로 앞 60%로 추정하고, 다음 20%로 추정 방식을 고르고, 마지막 20%로 예측을 검사합니다. 이후 기록을 AI의 학습 정답으로 쓰지 않습니다.
