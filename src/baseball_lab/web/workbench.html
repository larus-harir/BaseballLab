학습할 리그 환경

MLB만 선택하면 기존 실제 전이 학습입니다. KBO·NPB를 선택하면 공통 정책이 리그별 환경을 섞어 연습합니다.

기본 비중은 같습니다. 기록 수가 많은 리그가 자동으로 더 많이 선택되지는 않습니다.

혼합 시 리그별 실제 타석 빈도로 보정하며, 주자·아웃 변화는 MLB 관측 전이를 공통으로 쓴다는 가정입니다. KBO는 검사 시작 전 완료된 시즌, NPB는 검사 시작 전 관측 경기만 사용합니다. 리그 실력 환산이나 실제 리그 간 경기 재현은 아닙니다.

연구 상세

관측·행동·보상 설명

무엇을 알고 있나요?

AI는 아웃 수와 주자 위치를 보고 행동을 고릅니다. 상대의 선택은 미리 알 수 없습니다.

무엇을 선택하나요?

공격은 타석 진행 또는 번트, 수비는 승부 또는 고의볼넷을 고릅니다. 실제 기록이 충분한 선택만 사용합니다.

왜 반복해서 배우나요?

점수를 얻거나 막은 결과를 보상으로 받아 선택을 바꿉니다. 학습 전후 성적은 같은 상대에게 다시 겨뤄 비교합니다.

현실 야구와 비교할 때

사람의 실제 선택 빈도와 AI의 선택 확률을 비교합니다. 선수와 상황의 차이가 남아 있어 현실의 정답으로 읽지는 않습니다.

세 아웃 전에 한 점 득점하기 / 막기입니다. 전체 경기 승리와 다릅니다.

타석 진행에는 관측된 타격·주루·수비 결과가 함께 들어갑니다. 개별 스윙이나 수비 움직임을 따로 배우는 단계는 아닙니다.

개발자 정보 · 자료 연결과 진단

현재 보관 자료가 없으면 자동 수집이 허용된 제공 연결이 필요합니다. 공식 사이트의 접근 가능 여부와 자동 수집 허용은 다릅니다. 허용 근거가 없으면 요청하거나 가짜 자료로 대체하지 않습니다.

1. 공식 자료 올리기

공식 검색에서 기간을 정하고 CSV를 내려받은 뒤 여기에 올려 주세요. 원본은 이 컴퓨터에 보관하며 공개 업로드하지 않습니다.

공식 Statcast 검색 열기 ↗
어떤 자료가 필요한가요?

처음에는 2024년 정규시즌 5월 1일~6일처럼 짧은 기간을 권합니다. 구종·카운트·투구 결과가 있는 상세 투구 CSV가 필요합니다. 선수 시즌 합계 표로는 이 모델을 학습할 수 없습니다.

공식 페이지의 조회/내보내기 기능과 이용 조건을 확인하세요. 자동 수집 제한 문구가 있어 이 화면에서는 자동 수집하지 않습니다. 여러 날짜를 한 CSV로 내보내면 편합니다.

2. 실제 기록과 맞는지 검사하기

일부 기록으로 모델을 만들고, 나중 날짜의 기록으로 검사합니다. 같은 기록으로 만들고 검사하면 그럴듯해 보이는 착각이 생깁니다.

검사를 통과하면 믿어도 되나요?

기초 검사 통과는 제한된 실험을 시작할 조건입니다. 현실의 인과관계나 최적 전략이 입증됐다는 뜻은 아닙니다. 수비·주루·능력·피로처럼 검증되지 않은 요소는 사용하지 않습니다. 희소한 구간과 예측 오차는 결과 화면에서 확인하세요.
