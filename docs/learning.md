# 경기 승패로 배우는 E01

## 학습과 시뮬레이션의 역할

확률 모델은 행동이 주어졌을 때 경기 사건을 계산한다. 학습기는 그 사건의 정답을 맞추도록 훈련하지 않는다. 경기 전체의 최종 승패를 보고 선택 확률을 갱신한다. 삼진·안타·득점·스윙률은 보상에 더하지 않는다. 감마는 1이며 모든 해당 팀의 결정에 같은 최종 수익을 사용한다.

타자/투수는 각자 18개 공개 특징 → 24 → 24 → 행동 수의 tanh 신경망이다. 소프트맥스로 4개 타격 행동과 18개 투구 행동 중 하나를 확률적으로 선택한다. 상태 의존 전략을 직접 학습하며, 적극형/인내형을 학습 정답으로 쓰지 않는다.

REINFORCE 목적은 `- sum((최종 승패 - 이전 경기 수익의 이동평균) * log π(선택 행동 | 공개 상태)) / 배치 경기 수`다. 이동평균은 행동과 무관한 분산 감소 기준이며 점수·야구 지표 보상이 아니다. 8경기 배치, Adam, 전역 기울기 norm 5 제한을 사용한다. NumPy로 순전파·역전파를 구현했고 수치 미분으로 기울기를 검증한다. 정책 모방·사전 학습 데이터·보조 보상·엔트로피 보상은 없다.

## 경쟁 상대와 평가

현재 팀의 타자·투수 두 정책을 학습한다. 경기마다 선후공을 바꾸고, 학습 상대는 50% 고정 기준선, 50% 과거 팀 스냅샷 풀에서 뽑는다. 풀에는 학습 전 정책과 최근 최대 5세대가 포함된다. 평가 중에는 가중치·옵티마이저를 바꾸거나 의사결정을 학습 버퍼에 수집하지 않는다.

고정 기준선 3팀과 학습 전 팀에 대해 같은 평가 시드·선후공 교환으로 반복 평가한다. 과거 모델 상대의 별도 성적도 JSON에 기록한다. 승/패/무와 승률(승/전체 경기), 무승부에 0.5를 주는 평가점수율은 구별한다. 승률 구간은 선후공 쌍을 통째로 재표집하는 1,000회 bootstrap으로, 여러 학습 seed의 불확실성이나 모델 편향까지 나타내지 않는다. 1쌍만 평가한 경우 구간은 [0,1]로 둔다.

전략 변화는 매번 동일한 5가지 공개 상황을 입력한 행동 확률로 비교한다. 경기 중 경험한 상태 분포가 달라지는 효과와 구분하기 위한 것이다. 컨택 확률이 늘었다는 관측만으로 이유를 설명하지 않고, 모델/보상/상대 구성에 대한 개입 실험으로 확인한다.

## 경기 규칙과 현실 가정

3이닝 단축 경기가 기본이며 9이닝도 설정 가능하다. 이닝마다 3아웃, 선후공 교대, 마지막 이닝 홈 팀 리드 시 말 공격 생략, 끝내기, 최대 2이닝 연장 뒤 무승부를 처리한다. 볼넷은 밀어내기만 진루하고, 안타는 타구 유형의 루타 수만큼 주자를 진루시킨다. 희생 번트 아웃은 2아웃 전에 주자 한 베이스 진루, 2스트라이크 번트 파울은 삼진, 1루 주자·2아웃 전 땅볼은 합성 확률로 병살을 처리한다. 3번째 아웃이 된 플레이에 득점을 더하지 않는다.

주루는 보수적으로 고정되어 있고 타순별 선수·수비·도루·교체 정책은 아직 없다. 투수의 전력 투구는 접촉을 어렵게 하지만 제구와 누적 부하에 손해를 준다. 구속/물리 모델이나 실측 선수 능력이 아니라 제한된 합성 계수다. 현재 투구의 목표는 정책들이 동시에 결정한 뒤 결과 모델만 받는다. 타자가 이용할 수 있는 값은 그 전의 카운트·경기 상태·공개 투구 부하뿐이다.

승패를 인위적으로 만들지 않는다. 과도한 파울/반이닝 길이 safety limit은 예외로 종료하고 해당 경기의 보상을 계산하지 않는다.

## 저장·재평가와 재현

각 평가 시점마다 두 신경망과 Adam 상태, 역할, 특징 순서, 관측/행동 스키마, 훈련 경기 수, 리그·룰·합성 데이터 버전, seed, 코드 SHA256/Git revision, Python/NumPy 버전을 JSON에 저장한다. 로딩 시 버전·특징·역할·행렬 shape·유한값을 검사하며 pickle을 사용하지 않는다.

`--mode replay --checkpoint ...`는 원래의 이닝 규칙·평가 시드를 사용해 저장 정책을 고정한 채 재평가하고 재생한다. 중단 후 과거 상대 풀·랜덤 상태·수익 이동평균·전체 이력을 복원하는 이어 학습은 아직 제공하지 않는다. 같은 환경 버전·설정·seed의 새 실행 재현을 테스트한다. 다른 BLAS/NumPy/운영체제에서 부동소수점 차이로 확률 경계의 선택이 달라질 수 있으므로 환경 버전을 함께 보존한다.

## 실데이터·인간 야구와 비교

현재 모델은 synthetic-game-v1이다. 실제 MLB/KBO 전략을 발견했다는 결론을 내리지 않는다. 후속 실데이터 어댑터·분포 보정·현실 제약 검증을 통해 합성 모델 착시를 줄이고, 여러 학습 seed·여러 상대·보정 환경에서 재평가한다. 인간 야구의 역사/현대 기록은 출처와 이용 조건을 확인한 관측 데이터와 별도 분석으로 비교한다. 공통 GameEngine·정책 계약·체크포인트·평가·기록은 E02에도 재사용한다.
