# v4 · 근거 기반 보정과 제한된 경쟁 학습

## 원천과 품질

공식 Statcast HTTPS CSV 또는 사용자가 직접 공식 사이트에서 내보낸 CSV를 원본 그대로 보존한다. 자동 수집은 robots.txt 접근 규칙, 하루 단위 요청, 시간 간격, 최대 14일·요청당 32 MiB 상한을 지킨다. 접근 실패·HTML·잘못된 CSV를 기록하고 중단한다. 사용조건은 소프트웨어가 허가를 보증하지 않으며 출처별 확인 내용을 계보에 남긴다.

정규화는 원본 SHA256·획득 방법·조회 조건·raw/used N·제외 사유·중복 ID·키 충돌·결측률·단위·연도를 보존한다. 실제 기록에 없는 구종/의도/결과를 채우지 않는다. 정규시즌, 지원되는 물리 투구 설명만 사용하며 HBP·번트·자동 판정 등 미지원 설명은 제외 수를 기록한다. 연도를 섞지 않는다. 카운트 전이의 불일치도 검사한다. 수동 내보내기는 사용자 출처 진술이며 별도 독립 인증은 아니다.

## 보정과 검증

날짜와 경기 ID로 fit/validation/test를 분리한다. 모든 확률과 표본 풀은 fit에서만 만든다. 검증·최종 검증의 관측 행동을 조건으로 결과 분포와 예측을 비교한다. 현재 모델은 경험 빈도·계층적 풀링이며, 선택되지 않은 인간 행동의 인과 결과를 실측한 것으로 간주하지 않는다.

투구 도착(위치·구속·회전)은 카운트/구종의 실제 표본에서 먼저 재추출한다. 희소하면 동일 구종을 카운트 간 풀링한다. **이 물리 표본 선택에는 타자 행동을 넣지 않는다.** 결과 donor는 카운트·구종·도착의 기하학적 존 구간·선택 행동으로 조건화하고, 희소하면 구종/위치 효과를 단계적으로 풀링한다. 현재 정확한 좌표를 제어하는 투수 제구 정책이나 인간의 목표 코스는 모델링하지 않는다. 도착 donor와 결과 donor ID, 단계별 N/풀링, 실제 사용한 확률·Wilson 구간을 로그에 저장한다.

관측 위치 구간 안의 선택 편향·선수/상황 혼합과 반사실 인과 비식별 문제가 남는다. 이는 UNVERIFIED_ASSUMPTION이며 모델이 관측 분포를 맞춘다고 해결되지 않는다. 컨택/파워 의도, 번트, 능력, 피로, 주루·수비 효과는 미지원이다.

준비 기준은 기본 fit 500행·각 보류 100행, 모든 카운트/행동 풀 10표본, 보류 지원율 95%, validation 총변동거리(TV) 0.15 이하이다. 이는 사전에 고정한 **기술적 제한 PoC 진입 기준**으로 현실 타당성의 증명이 아니다. 기준·실패 셀을 artifact에 보존한다. 최종 test 오차도 별도 공개하며 모델 선택에 쓰지 않는다. 실제 데이터가 아니면 준비 기준과 무관하게 연구 실행을 막는다.

## 학습

부모 NeuralPolicy를 스키마/행동/특징 주입으로 재사용한다. 관측은 사전 카운트, 타자 행동은 스윙/테이크, 투수 행동은 지원되는 실제 구종이다. 도착 좌표·상대 행동·사후 센서값은 정책 입력에 넣지 않는다.

초기 P1 보상은 타석 종료 시 출루 +1/저지 -1의 **명시된 대리변수**이며, 투수는 부호가 반대다. 경기 승리 최적 AI라고 부르지 않는다. 단계별 실제 주루/수비 전이를 확보하기 전 기존 임의 경기 전이를 재사용하지 않는다.

두 은닉층 신경망을 역할별로 번갈아 학습하고 최종 타석 수익만으로 REINFORCE/Adam을 업데이트한다. 사람의 스윙/구종 비율을 정답으로 모방시키지 않는다. 학습 상대는 고정 균등 기준선과 과거 정책 풀을 혼합한다. 고정 상대·초기 정책·과거 정책을 같은 평가 seed와 N으로 비교한다. 평가 때는 업데이트하지 않는다. 정책 확률과 실제 경험 행동 빈도를 구별한다.

배치 업데이트마다 정책 버전 파일, 주기별 두 역할 체크포인트, 실제 관측 상태·행동 확률·선택·사건·대리보상·상대 정책 ID·모델/원본 ID를 보존한다. 재생은 데이터/모델/스키마/구종 순서가 일치해야 실행된다. 모든 상태를 복원하는 이어 학습은 아직 지원하지 않는다.

## 아직 실행하지 못한 것

현재 클라우드에서 공식 데이터 요청이 프록시 403으로 차단됐다. 실제 N·모델 오차·정책 성과는 미확인이다. 생성한 MOCK_TEST_ONLY 단위 테스트의 수치를 연구 화면/성과에 옮기지 않는다. 자료 확보 후 독립 검증을 먼저 수행하고 통과한 범위에서 연구 학습을 실행한다.
