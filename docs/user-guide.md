## 새 결과 화면과 이닝 학습

- **선수 가상 대결:** 선수와 연도를 선택하고 대결을 시작합니다. 요약 아래에서 예상/이번 결과 그래프를 보고, 사건 이름을 누르면 해당 타석으로 이동합니다. ‘그 밖의 결과’의 정의·미확인 사유는 바로 아래 설명을 열어 확인합니다. 계산 과정은 상단 **계산 원리** 탭에 있습니다.
- **Match:** ‘득점 기회 전략’과 ‘이닝 득점 전략’을 선택할 수 있습니다. 기간과 연습 횟수를 정하고 **AI 학습 시작**을 누르면 자료 준비부터 학습까지 자동 진행합니다.
- **이닝 결과:** 요약에서 같은 고정 상대에 대한 학습 전후 성적과 번트·고의볼넷 선택 변화를 봅니다. **학습하며 바뀐 선택**에서 반복·학습 단계·상황을 고르고, **장면 보기**에서 득점 후에도 세 아웃까지 이어진 진행을 살펴봅니다. 이닝 평균 득점은 9이닝 승률이 아닙니다.
- **자료와 검증:** 새 이닝 연구는 끝내기·연장 규칙의 혼입을 피하려고 세 아웃이 확인된 1~8이닝 전이를 사용합니다. 번트의 관측 선택 편향은 남아 있으며, 더 좋은 현실 전략을 입증한 결과로 해석하지 않습니다.

git pull origin main

열려 있던 서버는 Ctrl+C로 종료하고 다시 실행하세요. 웹 주소는 `http://127.0.0.1:8765`입니다. 자동으로 열리지 않으면 주소를 브라우저에 입력하세요.

- **선수 가상 대결:** 홈 → 대결하기 → MLB/KBO·시즌·선수·타석 수 → **대결 시작**. 핵심 수치·분포·타석별 장면을 봅니다. `계산 원리` 탭은 선택한 선수의 실제 기록과 보정 전후 수치, Log5·추첨·예측 검사를 연결합니다.
- **AI 전략 연구:** 홈 → 연구 보기 → 학습 시작 → 목표·기간·연습 횟수 → **AI 학습 시작**. 이닝 득점 전략과 득점 기회 전략의 보상·단위는 연구 상세에 구분합니다. 저장 결과에서 단계별 선택과 같은 상대에 대한 성적을 확인합니다.
- **개발자 정보:** 대결 화면의 세 번째 탭에 계산 방식·재현 번호·검증·원천 근거가 있습니다. `자료 관리`에서 원본 보관 상태와 삭제 영향을 확인합니다.

**다시 대결**은 같은 확률로 새 표본을 추첨하고, **같은 대결 재현**은 당시 조건·번호로 타석 순서를 복원합니다. 저장 당시 자료가 바뀌면 재현 오류를 표시하며 원본 결과는 유지합니다. 안타 수÷타석 수는 공식 타율과 다릅니다.

KBO 기본 집계는 앱에 포함되고, MLB 공식 배포는 처음 준비할 때 인터넷이 필요합니다. 이후 검증된 보관본을 재사용합니다. 미확인 사구·타구 종류는 임의로 채우지 않습니다. 원본 CSV/ZIP/과제 문서·생년월일·학교 항목은 배포에 포함하지 않습니다.

# 야구 연구실 사용 안내

첫 화면의 **야구 장면 보기**는 새 AI를 학습하지 않고 관람하는 곳입니다. **실험 설정하기**는 득점 전략을 연구할 조건을 고르는 화면으로 이동합니다. 실제로 학습을 시작하는 버튼은 설정 화면의 **AI 학습 시작**입니다.

## 야구 장면 보기

실제 경기 기록과 기록 기반 가상 공격을 구분해 고릅니다. 아웃·주자를 정해 **장면 불러오기**를 누르면 야구장 화면이 열립니다. 이전·다음·재생·일시정지·속도·장면 목록을 사용할 수 있습니다. 실제 기록 여부는 화면에 계속 표시합니다.

주자·아웃·이번 장면의 득점만 그립니다. 구속·공 궤적·선수 능력·알 수 없는 전체 경기 점수를 만들지 않습니다. 가상 공격의 ‘번트 선택 없이 진행’은 번트가 관측되지 않은 과거 플레이 묶음을 활용하는 것이며 타자의 개별 스윙 버튼은 아닙니다.

## AI의 선택 변화 보기

기본은 2024년 자료로 3,000번씩, 난수만 바꾸어 3회 반복 확인입니다. 공식 자료는 자동 준비합니다. 새 학습이 끝나기 전에도 저장된 시점까지 볼 수 있으며, 최종 성적은 마지막 확인 대결 후 표시합니다.

결과에서 상황과 학습 시점을 움직이면 **그 상황에서 AI가 선택할 확률**, **모든 학습 상황에서 실제 선택한 누적 횟수**, **같은 방식으로만 플레이하는 상대를 상대한 별도 성적**을 구분해 볼 수 있습니다. 누적 횟수는 지금 고른 한 상황의 횟수가 아닙니다.

같은 출발 장면을 학습 전과 선택한 학습 시점에 나란히 비교합니다. 저장하지 않은 상황에는 ‘장면 없음’을 표시합니다. 한 장면 차이로 개선의 원인을 단정하지 않습니다.

## ‘누가 더 잘하나요?’를 읽을 때

현재는 공격이 3아웃 전에 한 점을 내고 수비가 막는 다른 과제입니다. 50%가 같은 실력의 기준이라는 근거가 없어 ‘우세’ 판정을 하지 않습니다. 관측된 득점·차단 횟수와 각자 같은 상대에 대한 학습 전후 성적을 따로 봅니다. 전체 경기 승리나 현실의 최적 전략은 아직 검증하지 않았습니다.

기존 실행은 웹에서 새 해석과 화면으로 볼 수 있습니다. 과거 HTML 파일을 직접 열면 당시의 문구가 남아 있을 수 있습니다. 원문 연구 이력을 덮어쓰지 않기 때문입니다.

## 자료 관리

**자료와 신뢰성**에서 원본·사용자 비공개 자료·정제 자료·저장 모델·결과·기타 자료의 용량과 위치를 확인합니다. 공식 자료의 **원본 무결성 확인**은 원본 ZIP과 정제 기록의 해시를 검사하며 현실성·인과성 인증은 아닙니다.

**정리할 항목 확인**은 곧바로 지우지 않습니다. 대상·크기·확인된 관련 연구와 재현성 영향을 읽고, 체크한 뒤 최종 삭제를 눌러야 지워집니다. 학습 중에는 정리할 수 없습니다. 자동 삭제·휴지통 복원은 없고, 예전 조사자료·명령줄 결과 중 개별 검토가 필요한 영역은 자동 삭제 대상으로 열지 않습니다.

앱은 로컬 전용이며 자체 암호화하지 않습니다. Windows 권한·BitLocker·OneDrive/백업 보호는 해당 PC에서 따로 확인해야 합니다. [실제 점검 범위](security-audit.md)를 보세요.

## 중지·종료

현재 학습 중지는 실제 하위 프로세스를 멈추고 미완료 기록을 남깁니다. 이어 학습은 아직 지원하지 않으므로 새로 시작합니다. 서버 종료는 터미널의 Ctrl+C입니다. 바뀐 화면을 적용할 때도 기존 서버를 종료하고 다시 실행하세요.

## 파일과 재현

- `data/local/retrosheet/official-2024/`: 공식 원본 ZIP·CSV·고지·정규화된 데이터.
- `outputs/workbench/<실행 ID>/result/`: report.html, summary.md, research.json, models.json, checkpoints.
- research.json에는 실제 데이터 ID, 환경 ID, 실행 ID, 소스 해시, 설정, 평가와 리플레이가 들어갑니다. 가중치는 checkpoints에 저장합니다.

터미널에서도 같은 연구를 실행할 수 있습니다.

```powershell
python scripts/quickstart.py --mode scoring --start 2024-03-20 --end 2024-09-30 --episodes 3000 --seeds 41,42,43 --evaluate-every 1000 --evaluation-n 500 --open
```

결과 폴더는 실행마다 새로 만듭니다. 명시한 `--output`에 기존 결과가 있으면 덮어쓰지 않습니다. 동일 자료·코드·설정·seed로 재실행하면 행동·평가를 비교할 수 있습니다. 결과 생성 시각과 로컬 파일 경로는 달라질 수 있습니다.
