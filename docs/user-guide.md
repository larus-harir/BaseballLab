# 새 화면에서 시작하기

첫 화면에서 **시뮬레이션 열기**는 학습 없이 야구 상황을 관찰하고, **AI 학습 시작**은 Match 연구실로 갑니다. Match-B에서 기본 설정으로 학습을 시작하세요.

완료 후 **이번 결과 한눈에 보기**를 누르면 현재 우세·학습 전후 개선·시간에 따른 변화부터 나옵니다. 우세가 불분명하면 결론을 보류합니다. 플레이·상세 비교·자료 근거는 별도 탭입니다. 이전 실행에서도 같은 요약을 볼 수 있고, 그 이전 기록은 접어서 표시합니다.

Match-A는 개별 스윙/기다리기·구종의 기존 경로이며 별도 실제 자료 연결이 필요합니다. Match-B의 한 점 득점과 전체 경기 승리는 구분합니다. 자료 기간은 검증한 2023·2024 중 한 시즌을 지정할 수 있고 기본은 2024입니다.

# 야구 AI 연구실 사용 안내

## 시작과 학습

README의 설치 명령을 한 번 실행한 뒤 `python scripts/quickstart.py --open`으로 엽니다. 기본 **E01-R1 · 득점 / 실점 방어 학습**을 선택하고, 2024년 정규시즌 기간과 학습량을 확인한 뒤 **AI 학습 시작**을 누르세요. CSV 업로드는 필요하지 않습니다.

처음에는 공식 Retrosheet 2024년 배포를 자동으로 받아 저장합니다. 다음부터는 보관 자료의 체크섬을 확인하고 재사용합니다. 자료 준비·검사·학습 단계가 화면에 표시됩니다. 두 AI는 과거·고정 상대와 경쟁하며 마지막 득점 성공·실패만으로 학습합니다. GPU는 필요하지 않습니다.

기간을 줄일 수 있지만 아웃·주자 상태별 실제 표본이 부족하면 구체적인 이유를 표시하고 멈춥니다. 우선 기본 시즌 전체를 권합니다. 같은 시즌 자료를 재사용하되 선택한 날짜의 기록만 모델에 사용합니다. 앞선 실제 경기 날짜 60%는 모델 만들기, 다음 20%는 검사, 마지막 20%는 학습 종료 후 독립 확인에 사용합니다. 재개된 경기는 원래 경기 ID 날짜로 묶어 분리 누수를 막습니다.

기본 3,000상황은 첫 seed의 학습량입니다. 다음 두 seed에서도 같은 학습량으로 반복합니다. seed는 같은 자료·설정으로 재현하는 난수 번호이며 실력 점수가 아닙니다. 진행률은 현재 seed의 실제 체크포인트 로그를 표시합니다.

## 결과 보기

체크포인트를 저장하면 **결과 보기**를 누를 수 있습니다. 진행 중 열린 보고서는 새로고침하면 이후 기록이 나타납니다.

1. **학습 변화:** 같은 아웃·주자 상태에서 번트·고의볼넷 확률이 어떻게 변했는지 봅니다. 이는 신경망 출력이며 경험한 행동 빈도와는 다릅니다.
2. **리플레이:** 학습 시점·seed·시작 상황을 골라 한 턴씩 넘깁니다. 아웃·주자, 선택 확률·행동, 결과, 원천 플레이를 확인합니다. 투구별 자료가 없어 공 궤적·스트라이크존을 만들지 않습니다.
3. **상대 평가:** 고정·초기·과거·사람 관측 빈도 상대와의 득점률을 봅니다. 투구 측에는 득점률이 낮을수록 좋습니다. 교차대결의 행은 타격 측, 열은 투구 측 학습량입니다.
4. **현실과 차이:** 실제 날짜·표본 수·상황별 전이 분포 오차를 봅니다. 전체 평균만으로 합당성을 판단하지 않습니다.

오차 구간은 가상 대결의 난수 오차만 보여 줍니다. 데이터 표본·선수 구성·선택 편향까지 포함한 신뢰 구간은 아닙니다. 사람 관측 빈도 상대도 실제 인간 팀이 아닌 별도 고정 정책입니다. 대조 실험은 번트의 관측 전이를 일반 전이로 바꿔 결과 의존성을 확인하며, 현실의 번트 효과를 입증하지 않습니다.

## 지금의 한계

현재는 세 아웃 전에 한 점 이상 내기 / 막기입니다. 출루율 보상과 다르지만, 전체 경기 승리와도 다릅니다. 24개 아웃·주자 상황을 같은 비중으로 시작하는 실험이며 실제 경기 빈도가 아닙니다. 타격 측·투구 측의 거친 선택을 다루고, 구종·코스·컨택/장타 의도·선수 능력·직접 주루/수비 제어는 지원하지 않습니다.

‘번트 시도가 있었던 턴’이라는 관측 분류에는 인간의 선택 편향이 남아 있습니다. 기록이 없는 상황으로 효과를 확대하지 않으며, 이 모델에서의 성과를 현실의 최적 전략으로 주장하지 않습니다.

## 중지와 문제 해결

**현재 작업 중지**는 미완료 기록을 남기고 해당 학습을 멈춥니다. 이어 학습은 아직 지원하지 않으므로 새 실행을 시작하세요. 서버 종료는 터미널의 Ctrl+C입니다.

공식 다운로드가 차단되면 네트워크 오류를 기록하고 멈춥니다. 현재 필요한 도메인은 `www.retrosheet.org`입니다. 가짜 자료나 다른 기간으로 조용히 바꾸지 않습니다. 체크섬 변경은 공식 수정 배포 여부를 확인해야 하므로 기존 확인값을 임의로 바꿔 통과시키면 안 됩니다.

## 파일과 재현

- `data/local/retrosheet/official-2024/`: 공식 원본 ZIP·CSV·고지·정규화된 데이터.
- `outputs/workbench/<실행 ID>/result/`: report.html, summary.md, research.json, models.json, checkpoints.
- research.json에는 실제 데이터 ID, 환경 ID, 실행 ID, 소스 해시, 설정, 평가와 리플레이가 들어갑니다. 가중치는 checkpoints에 저장합니다.

터미널에서도 같은 연구를 실행할 수 있습니다.

```powershell
python scripts/quickstart.py --mode scoring --start 2024-03-20 --end 2024-09-30 --episodes 3000 --seeds 41,42,43 --evaluate-every 1000 --evaluation-n 500 --open
```

결과 폴더는 실행마다 새로 만듭니다. 명시한 `--output`에 기존 결과가 있으면 덮어쓰지 않습니다. 동일 자료·코드·설정·seed로 재실행하면 행동·평가를 비교할 수 있습니다. 결과 생성 시각과 로컬 파일 경로는 달라질 수 있습니다.

## 기존 Statcast 실험

연구 자료에서 **E01-R0**을 고르면 기존 스윙/기다리기·구종 선택 출루 연습을 사용합니다. 별도 공식 내보내기 자료나 허용된 연결이 필요하며, 고급 설정에서 한 번 연결한 자료를 재사용합니다. 자동 스크립트 수집의 별도 허용을 확인하지 않은 채 다운로드하지 않습니다. 이 경로는 득점·승리 보상과 구분합니다.
