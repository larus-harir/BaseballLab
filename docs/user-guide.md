# 웹 연구실 사용 안내

기본은 기간을 고르고 **AI 학습 시작**을 누르는 한 번 실행입니다. 아래 원본 업로드·개별 검사 안내는 고급 설정을 사용하는 경우입니다.

## 처음 한 번

Python 3.11 이상 설치 후 README의 설치 명령을 실행합니다. 이후 `python scripts/quickstart.py --open`으로 연구실을 열면 됩니다. 자동으로 설치된 프로그램을 실행하는 명령은 이 한 줄입니다. 서버와 학습이 작동하는 동안 터미널을 닫지 마세요.

## 자료가 없다고 나오면

공식 https://baseballsavant.mlb.com/statcast_search 에서 원하는 짧은 기간의 정규시즌 **상세 투구**를 조회하고 CSV로 내보내세요. 파일을 올릴 때 실제 조회 주소·획득 시각·이용 조건 메모를 기록합니다. 이는 사용자 출처 확인이며 소프트웨어가 독립적으로 원본 진위를 인증한다는 뜻은 아닙니다.

기본 예시는 2024-05-01~06입니다. 5월 1~3일은 모델 만들기, 4일은 검사, 5~6일은 마지막 독립 확인에 쓰도록 날짜가 설정돼 있습니다. 다른 기간을 받았다면 ‘검사 시작일’, ‘마지막 독립 확인 시작일’을 변경하세요. 한 날짜밖에 없으면 세 기간으로 나눌 수 없습니다.

CSV가 아닌 파일, 시즌 합계 표, 빠진 필수 열, 모순된 기록은 거절합니다. 원본의 결측값을 임의로 0으로 바꾸어 통과시키지 마세요. 화면의 오류 설명과 ‘자세한 기록’을 확인하세요.

## 모델 검사가 통과하지 않으면

투구 기록이 부족하거나 희소한 카운트가 있을 수 있습니다. 세부 오류는 결과 보기의 현실 검증 화면에 있습니다. 다른 구종/상황의 오차가 서로 상쇄되어 전체 비율만 비슷할 수도 있으므로 조건별 검사도 합니다. 단순한 카운트·행동 기준 모델보다 예측이 더 나빠지는지도 검사합니다. 기준을 낮춰 억지로 학습을 실행하기보다 자료 범위·정의·모델을 재검토하세요.

기초 검사를 통과해도 인간의 행동을 바꿨을 때 결과가 같을 것이라는 인과 타당성은 입증되지 않습니다. 현재 ‘타석 연습 가능’ 표시는 그 제한 안에서 실험을 시작할 수 있다는 뜻입니다.

## 학습할 때

타석 수는 학습 예산, 재현 번호(seed)는 난수 재현 설정입니다. 같은 자료와 환경에서 같은 설정으로 확인할 수 있습니다. CPU에서 작동하며 GPU는 필요하지 않습니다. 초기 정책과 고정 상대·과거 모델을 비교합니다. 학습 타석 수와 평가 타석 수는 다릅니다.

진행 상황은 실제 로그가 출력된 시점마다 갱신합니다. 그 사이의 진행률이나 남은 시간을 임의로 추정하지 않습니다. 결과 보기는 중간 체크포인트가 저장되면 사용할 수 있으며 새로고침하면 이후 기록을 볼 수 있습니다. 중지한 실행은 미완료로 남고 이어 학습은 지원하지 않습니다. 새 실험을 시작하세요.

## 결과를 읽을 때

- ‘실제 기록’: 원본에서 관측한 투구입니다.
- ‘자료로 추정’: 훈련용 기록으로 계산한 모델 값입니다.
- ‘모델의 플레이’: AI가 추정 모델에서 선택한 가상 결과입니다.
- ‘아직 검증하지 못한 부분’: 가정과 선택 편향 등입니다.

타자·투수가 선택 전에 봤던 카운트와 실제 선택 확률, 결과를 구분합니다. 스트라이크존 점은 도착 위치이며 전체 비행 궤적이나 투수의 의도한 코스가 아닙니다. 없는 값은 데이터 없음으로 표시합니다.

지금 성공률은 출루 대리보상 결과입니다. 실책·선택수비 출루도 포함할 수 있어 공식 OBP와 같지 않습니다. OPS는 출루율과 장타율의 합이며 확률이 아닙니다. 단일 seed의 좋아진 성적을 최적 전략으로 단정하지 말고 다른 상대·기간·seed에서도 확인하세요.

## 터미널에서 직접 실행하는 경우

```powershell
python scripts/quickstart.py --mode audit --csv "C:\Data\statcast.csv" --source-url "https://baseballsavant.mlb.com/statcast_search" --acquired-at "2026-11-04T23:00:00+09:00" --usage-note "실제 확인한 이용 조건과 조회 기간"
python scripts/quickstart.py --mode fit --train-before 2024-05-04 --test-from 2024-05-05 --open
python scripts/quickstart.py --mode train --episodes 600 --open
python scripts/quickstart.py --mode replay --checkpoint "outputs/E01/실행폴더/checkpoints/pa_000600.json" --seed 42 --open
```

예시 획득 시각·경로는 실제 값으로 바꾸세요. 자동 다운로드 명령은 별도 허용 근거가 없는 한 실행을 거부합니다. 공식 약관/robots 허용은 서로 다른 문제이며, 접근 가능한 페이지라는 이유로 수집·재배포 허가를 가정하지 않습니다.

## 기간을 골라 한 번에 실행하기 (0.6)

기본 화면에서 기록 시작일·종료일을 선택하고 **AI 학습 시작**을 누릅니다. 프로그램은 해당 기간의 확인된 보관 자료를 찾아 정확히 필터링합니다. 자료가 없으면 별도로 자동 수집이 허용된 연결만 사용합니다. 이후 모델 만들기/검사/독립 확인의 기간을 자동 분리하고, 검사를 통과하면 학습합니다. 실패하면 다른 기간이나 합성 자료로 바꾸지 않고 멈춥니다.

현재 공식 사이트 자동 수집 허용 근거는 확보하지 않았습니다. 자료 제공 연결이 없고 보관 자료도 없으면 ‘자료 연결 필요’로 종료됩니다. 허용 근거는 고급 설정에서 한 번 연결할 수 있으며 비밀번호/API 키를 입력하는 칸은 아닙니다. 원본 업로드와 수동 모델 검사도 고급 설정에 남겨 두었습니다.
