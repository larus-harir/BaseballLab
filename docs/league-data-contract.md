# 여러 리그 자료를 함께 쓰는 규칙

원천과 의미를 유지하면서 대결·학습·리그 비교에 재사용합니다. 기존 계산은 보존하고 아래 공통 기록 비교·여러 시즌 학습 경로를 추가했습니다.

| 구분 | 필수 조건 | 빠진 경우 |
|---|---|---|
| 자료 등록 | 리그, 시즌, 역할, 원천 내 ID, 집계 단위, 원본 SHA-256 | 등록 거부 |
| 계수 | 음수가 아닌 정수, 타석·타수·안타·장타 간 정합성 | 모순된 자료 거부 |
| 타석 사건 구성 | 타자 PA 또는 투수 TBF와 H·2B·3B·HR·SO·BB·HBP | 하나라도 없으면 사건 구성 불가 |
| 전략 학습 | 실제 관측 상태·행동·보상·시간 순서와 별도 모형 검증 | 시즌 합계를 실제 행동 전이로 간주 금지 · 별도 주변 빈도 보정은 아래 조건 적용 |
| 리그·시대 간 능력 비교 | 규칙·시대·구장·상대 수준 보정 및 검증 | 같은 열 이름만으로 동등한 능력이라 주장 금지 |

- 값이 없으면 `null`과 사유를 저장합니다. 미수집, 미공개, 정의 불명확, 해당 없음으로 구분하며 0으로 보충하지 않습니다. 원문의 미등록 열도 `source_fields`에 남깁니다.
- 이닝은 아웃 수(`IP_OUTS`)로 통일합니다. 16.1이닝은 49아웃입니다. 비율은 원래 분모를 보존하며 서로 다른 분모를 합치지 않습니다.
- 선수 식별자는 제공자·리그·시즌·역할 범위 안에서만 유효합니다. 이름만으로 리그·연도·팀을 넘어 같은 선수라고 연결하지 않습니다. NPB 선수 표의 ID는 행 식별용이며 확인된 개인 ID가 아닙니다.
- 팀 시즌 합계, 선수 시즌 합계, 선수의 팀별 분할을 구분합니다. 동일 개체의 전체 합계와 팀 분할을 함께 합산하지 않습니다. 동일 수집본은 중복 계산하지 않고, 같은 개체의 수정 수치가 충돌하면 검토하도록 실패시킵니다.
- KBO 제공 자료의 `HP`는 정의 확인 전 `HBP`로 바꾸지 않습니다. NPB 투수 표에 없는 피2루타·피3루타·타수도 추정하지 않습니다. 공개 접근 가능 여부와 학습·재배포 권한은 별도 상태로 보존합니다.
- 최근 N시즌은 **각 리그에서 확보한 최근 N시즌**입니다. 연도가 빠져 있거나 최신 시즌이 늦으면 결과 manifest에 드러납니다. 기간 미지정은 확보한 전체 자료이며 실제 전체 역사와 같다는 뜻은 아닙니다.

`python scripts/prepare_league_data.py --leagues MLB NPB --start-season 2020 --end-season 2025`로 범위를 제한합니다. 표준 결과는 `data/local/standardized/<dataset_id>/`에 새 버전으로 저장합니다. 원본·기존 카탈로그·학습 결과는 덮어쓰지 않으며 자료와 가중치는 Git에 넣지 않습니다. 결과는 적격 여부와 한계를 담은 manifest 및 행별 JSONL입니다.

## 현재 시뮬레이션에서의 사용

- **EraMatch 공통 비교** `/eramatch?mode=common`: PA/TBF와 SO·BB·H가 모두 있는 선수만 사용합니다. 사건은 삼진·볼넷·안타·나머지이며 분모에서 알려진 세 계수를 뺀 나머지를 보존합니다. 나머지는 아웃과 동의어가 아니며 사구·희생타·실책 출루 등이 포함됩니다. 피장타 분할과 HP 정의가 불명확해도 이 네 사건에 필요한 실제 계수가 있으면 비교할 수 있습니다. 0타석 선수는 제외합니다.
- 먼저 원래 리그 평균을 100타석만큼 섞고(탐색용 기본값, 0~2,000 조절 가능), 그 비율을 원래 리그·시즌 평균으로 나눠 선택한 기준 환경으로 옮깁니다. 이후 기존 다항 Log5 엔진으로 결합하고 기존 추첨·저장 시스템으로 실행합니다. 선수 합계와 팀 합계를 함께 더하지 않습니다. 팀 타격 합계가 있으면 그것을 기준으로, 없으면 확보한 선수들의 합계로 평균을 구합니다.
- 이 보정은 **리그 평균 대비 상대 빈도의 운반 가정**입니다. 리그 간 절대 수준, 구장·수비·상대 수준을 식별한 환산 계수가 아닙니다. 이런 계수를 지어내지 않으며 결과에 검증 전 상태와 보정 전후 수치를 남깁니다. KBO 제공 기록의 독립 검증·확보 선수 범위 편향도 표시합니다. 미래 실제 리그 교류·이적 표본의 검증 없이 절대 실력 환산으로 승격하지 않습니다.
- **Match 수집 기간 학습**: 확보한 MLB 실제 플레이의 전체/최근 5시즌/단일 시즌을 웹에서 선택합니다. 같은 정제기에서 주자·아웃·득점 연속성과 고의볼넷 규칙을 검사하고, 실제 최종 플레이 날짜로 경기 전체를 묶습니다. 정규 1~8회 중 세 아웃까지 확인된 이닝만 사용해 끝내기·연장 자동주자 규칙을 동일 환경에 섞지 않습니다. 시즌 합계를 개별 관측 전이로 추가하지 않습니다.
- 날짜 앞 60%는 모형 작성, 다음 20%는 점검, 마지막 20%는 학습 후 확인입니다. 합법 행동은 앞 두 구간의 표본으로만 결정합니다. 마지막 구간에 표본이 없으면 임의 대체하지 않고 실패합니다. 여러 시즌의 관측 빈도로 만든 환경이며 정책 변화의 인과 검증이나 시즌별 동일 가중 능력 추정은 아닙니다. 원본 해시·사용 시즌·모집단과 시간 분리를 결과에 기록합니다.

## 출처별 사용 결정

| 원천 | 현재 허용 경로 | 제외 경로·근거 |
|---|---|---|
| Retrosheet MLB | 출처 고지를 유지한 통계 비교·실제 전이 기반 제한적 학습 | 없는 구종·구속·좌표 생성 금지 |
| 사용자 제공 KBO | 로컬 과제 재현·공통 계수의 탐색 비교 | 공식 사이트 승인 없는 자동 수집, 시즌 합계를 실제 행동 기록으로 바꾸는 사용 제외 |
| 공식 NPB 공개 표 | 확보본 보존·원천 점검 | 별도 허용을 확인하기 전 새 시뮬레이션·학습·기준 환경 선택 차단 |
| Kaggle KBO 배포 CSV | CC BY-NC-SA/CC0 등 게시자 선언을 보존한 로컬 탐색 비교·품질 대조 | 원천 검증 완료로 주장하지 않음. 계수 모순이 있는 주루 표와 시즌 합계를 행동 전이로 사용하지 않음 |
| armstjc NPB / SPAIA CSV | 게시자 데이터 사용·출처 표시 선언에 따라 정규시즌 식별이 가능한 선수 기록의 로컬 탐색 비교 | upstream 재배포권·완전한 시즌 포괄을 확인했다고 주장하지 않음. PBP를 검증 없이 정책 학습에 사용하지 않음 |

2026-11-12 한국 시간에 [NPB 공식 홈페이지](https://npb.jp/) 하단의 `掲載の情報、画像、映像等の二次利用および無断転載を固く禁じます。`(게재 정보·이미지·영상 등의 2차 이용 및 무단 전재를 금지)를 확인했습니다. 이전의 단순 `미확인`과 구별해 실행 정책에 반영합니다. 공개 열람이나 사용자 개발 요청으로 제공자의 별도 허가가 생기는 것으로 간주하지 않습니다. 금지 대상 자료를 임의로 환산해 학습에 넣거나 다른 경로로 우회 수집하지 않습니다.

이 조건을 NPB라는 리그 전체에 적용하지 않습니다. 별도 배포자의 CSV는 실제 출처와 선언 조건으로 판단합니다. 원래 공식 NPB 사이트 수집본과 SPAIA 출처 비공식 배포본은 다른 제공자로 유지합니다. 비교 기준의 제공자는 리그·시즌마다 하나만 선택하며 현재 우선순위는 Kaggle netsong KBO 최신본 → armstjc NPB → Retrosheet → 기존 제공 KBO입니다. 같은 시즌의 다른 배포본을 더해 타석 수를 늘리지 않습니다. 전체 원본과 대안은 남기고 선택 제공자를 결과에 기록합니다. 원본 수집 실적과 누락·제외 수치는 [수집 현황](data-collection-status.md)에 있습니다.

실행 검증: 실제 MLB 2024~2025의 4,859경기·330,115전이로 연결·날짜 분리·양쪽 정책 갱신을 확인했습니다. 짧은 실행 검사이며 전략 우수성의 연구 결과가 아닙니다.

## 기존 화면의 자료 사용

기본 `/eramatch` 선수 선택과 기존 `/api/matchup/catalog`, `/api/matchup/analyze`에 수집 자료를 연결했습니다. 새 수집 ID는 기존 대결·저장·재현 경로로 실행되고, 이전 ID와 `data_mode=legacy`는 원래 모형으로 유지합니다. 수집본이 없는 설치는 포함된 KBO 기록과 이전 준비 경로를 사용하며 NPB를 KBO로 대체하지 않습니다. MLB는 실제 사건이 완비된 경우 8사건, KBO·NPB는 공통 4사건을 사용합니다. 다른 시즌의 세부 잔여 사건을 임의로 혼합하지 않습니다.

실제 기록 패널은 MLB 전체 수집 시즌의 투구 결과 코드·타구 종류와 수비 포지션, KBO의 선수 계수와 별도 팀 주루·수비 원문, NPB의 선수 ID가 일치하는 구속값 포함 원문 예시를 연결합니다. SPAIA ID의 `123`과 CSV의 `123.0`만 정수 표현으로 정규화하며 이름으로 대응하지 않습니다. 구속은 제공자의 보고값이며 계측 정확도를 인증하지 않습니다. NPB 좌표는 원문 값만 보존합니다. 두 주루 버전은 더하지 않고, 모순된 시도 수는 고쳐서 확률에 넣지 않습니다.

2000년 수집 기록에서도 2,429경기·171,457전이를 사용한 짧은 실행으로 양쪽 정책 갱신을 확인했습니다. `IW.2-3(WP)`처럼 고의볼넷과 폭투가 결합된 9회 기록 때문에 과거 정제기의 전 이닝 강제 진루 검사가 실패하는 경우를 확인했습니다. 원본과 전체 불일치 계수는 보존하고, 새 수집 경로의 규칙 검사는 실제 사용하는 **세 아웃까지 완료된 1~8회** 모집단에 한정했습니다. 이전 정제 경로의 검사 조건은 변경하지 않았습니다. 이 보완을 원본과 기존 모델을 덮어쓰는 방식으로 적용하지 않습니다.

## 리그 환경 혼합 학습

기존 이닝 신경망·행동·최종 득점 보상·경기 단위 날짜 분리를 재사용합니다. 선택 리그의 비중을 정규화하고 이닝 시작마다 환경을 하나 선택합니다. 하나의 공통 정책은 리그 이름을 관측하지 않습니다. 공격은 총득점을 높이고 수비는 낮추며 중간 보상이나 권장 전략을 추가하지 않습니다. 계획 비중과 실제 방문 횟수는 구분해 저장합니다.

공통 4사건(삼진·볼넷·안타·나머지)을 MLB 실제 완료 타석 전이와 원본 ID로 연결합니다. 학습 구간의 MLB 사건 빈도를 기준으로 각 리그의 사건 빈도 비율을 구하고, 같은 아웃·주자·행동에서 관측된 전이의 표집 비중을 조정합니다. 식은 `리그 사건 빈도 / 학습 구간 MLB 사건 빈도`이며 관측 셀 안에서 정규화합니다. 존재하지 않는 결과를 만들거나 실제 주자 변화를 다시 쓰지 않습니다. 타석이 아닌 주자 사건은 별도로 남기며, 고의볼넷은 기존 강제 진루 규칙을 유지합니다. 사건별 묶음을 먼저 추첨해 대규모 원본 전체를 매 턴 검색하지 않습니다.

보정 자료의 시간 기준:

- MLB 기준은 모형 작성 구간만 사용합니다. 검사·최종 확인 구간의 사건 빈도로 기준을 조정하지 않습니다.
- KBO는 검사 시작 연도보다 앞서 완료된 가장 최근 시즌을 사용합니다. 연중 시즌 합계에 미래 경기가 섞이는 문제를 피합니다.
- NPB는 종류명과 ID가 정규시즌으로 확인되고, 원천 경기 날짜가 검사 시작일보다 앞선 선수 경기 행만 합칩니다. 확인할 수 있는 앞 기간이 없으면 시작 전에 계수 보정을 실패시키며 미래 기간으로 대체하지 않습니다. 현재 수집본에서는 2025년 기간을 권장합니다.
- 날짜 분리는 원천 날짜를 기준으로 한 회고 실험입니다. 최신 다운로드 버전이 당시에도 공개돼 있었다는 as-of 검증이나 오류 수정 이력의 독립 검증을 뜻하지 않습니다. NPB의 원천 `game_date`와 MLB의 실제 최종 플레이 날짜 의미도 별도 기록합니다.

이 방식은 **리그별 타석 주변 빈도를 반영한 공통 조건부 전이의 운반 가정**이며 실제 KBO·NPB 주자 전이를 확보·검증했다는 주장이 아닙니다. 리그 간 절대 실력 보정도 아닙니다. 조건별 표본 선택, 구장·상대 수준, 번트 효과의 혼입, 일부 자료의 고의볼넷 분리 차이는 남습니다. 특정 셀에 없는 사건을 목표 빈도에 맞추려고 추가하지 않으므로 조건부 분포가 리그 전체 빈도와 정확히 일치한다는 보장도 없습니다.

리그 환경별 평가는 학습 중 고정한 보정값과 보류한 MLB 전이에서 같은 정책·고정 상대를 다시 실행합니다. 독립 KBO·NPB 경기 전이에 대한 예측 검증과 구분합니다. 원본 해시·데이터 ID·선택 비중·실제 경험 이닝·보정 기간·리그별 전후 성적을 저장하고, 기존 단일 리그 연구와 가중치는 덮어쓰지 않습니다. NPB 게시자 출처 표시를 결과에 유지하며 upstream 권리·정확성 확인 상태는 기존 수집본과 동일하게 보존합니다.

실제 실행 검사: 3개 리그 혼합 40이닝·1개 난수와 웹 혼합 20이닝씩·3개 난수에서 양쪽 정책 갱신, 리그별 경험 횟수, 결과 재열기를 확인했습니다. 검사 시작일 2025-07-13 기준으로 KBO 2024 전체 기록과 NPB 2025-03-28~07-12의 36,358타석을 보정에 사용했습니다. 짧은 실행 검사는 정책 우수성이나 리그 간 타당성의 입증이 아닙니다.
