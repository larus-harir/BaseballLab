# 다음 연구 과제

공식 이용 조건에 맞게 확보한 실제 상세 투구 CSV를 웹 연구실에 가져와 자료 감사·시간 분리 보정·검사를 실행한다. 전체 평균과 조건별 오차, 단순 기준 모델보다 나쁜지, 표본 부족과 선택 편향을 확인한 뒤 현재 타석 경쟁 학습을 수행한다. 다른 seed·기간·상대에서 재확인하고, 경기 승패 보상으로 확장하기 전 주루·수비·득점 전이의 실측 근거를 확보한다.

첨부 과제에서 검토한 평균 회귀·시대 보정·Log5는 검증할 가설/후보 모델이지 현재 환경의 정답이 아니다. 고정 안정화 상수나 인플레이 타구 제어 능력을 무조건 0으로 두는 가정을 가져오지 않는다.
