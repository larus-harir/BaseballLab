# 다음 개발 요청 제안

“Baseball AI Lab M2를 진행해 줘. M1 공통 엔진과 E01을 유지하고, 공식 Statcast 설명과 이용 조건을 확인해 2024 정규시즌의 작은 날짜 범위 데이터를 재현 가능하게 가져오는 어댑터를 추가해 줘. 원본 캐시·출처/버전·단위·결측 사유·품질 리포트와 시간순 분할을 기록하고, 투구 결과의 조건부 분포를 synthetic-v1과 비교해 별도 보정 모델을 검증해 줘. 네트워크 없는 테스트에는 작은 출처 명시 fixture를 사용하고 실제 수집 성공 여부를 구분해 줘. KBO는 접근·이용 조건 및 공통 피처 가용성 조사와 E02 어댑터 설계만 진행해 줘. 관측 누수·희소 표본·연도별 정의 차이를 검증하고, 아직 전체 경기나 RL 학습을 구현하지 말아 줘.”

M3 전체 경기/승리 보상 → M4 E01 학습·스냅샷 평가 → M5 관찰 보고 → M6 E02 순으로 진행한다. E02 실구현은 KBO 데이터 조건과 공정성 계약을 확인한 뒤 진행한다.
