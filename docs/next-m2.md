# 다음 개발 작업

“Baseball AI Lab의 다음 단계인 M2를 진행해 줘. 현재 공통 엔진·정책·평가·투구 기록을 재사용해서, 공식 Statcast 설명과 이용 조건을 확인하고 2024 정규시즌의 작은 날짜 범위 데이터를 재현 가능하게 수집·캐시·표준화해 줘. 출처·버전·단위·결측 사유·품질 리포트와 시간순 분할을 기록하고, 카운트·구종·위치별 관측 분포를 synthetic-v1과 비교해 별도 보정 모델을 검증해 줘. 실제 투구 관측은 타자의 행동 전 정보에 누수되지 않게 해 줘. 네트워크 없는 검증에는 출처를 명시한 작은 fixture를 쓰고 실제 수집·보정의 성공 여부를 따로 보고해 줘. KBO는 접근·이용 조건과 공통 특징 가용성을 확인해서 E02에 연결할 어댑터 설계를 구체화해 줘. 검증 결과와 재현 명령을 기록하고 커밋·푸시해 줘.”

M2 결과를 바탕으로 전체 경기의 주자/득점/이닝과 현실 제약을 연결하고, 경기 승패만을 보상으로 하는 E01 경쟁 학습을 진행한다. 최종 연구 목표와 E02의 공정한 교차 평가 조건은 [개발 단계](roadmap.md)에서 함께 관리한다.
