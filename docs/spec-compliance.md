| 요구 | 구현 | 실제 검증/남은 조건 |
|---|---|---|
| 임의 확률·능력 감사 | docs/data-audit-v4.md, 합성 연구 경로 차단 | 파일별 분류 완료 |
| 실제 CSV·계보·품질 | data/statcast.py, lineage.py | 원천 접근 403, 실제 자료 미확보 |
| 보정/보류 분리 | outcome/empirical.py | 테스트 전용 자료로 알고리즘 검증; 실데이터 미실행 |
| 두 AI 업데이트·과거 상대 | research/training.py, 공통 NeuralPolicy | 업데이트·재현·저장·재생 기술 검증; 실제 연구 학습 보류 |
| 정책·사건·원천 추적 | events.jsonl, policy_versions/, checkpoints/ | 단위 테스트로 원천·확률·버전 연결 검증 |
| 스트라이크존·재생 | tracking/evidence_view.html | 브라우저에서 실제 데이터 대기/테스트 전용 조작 검증 |
| 전략·현실 검증 화면 | 같은 HTML의 로그 그래프·보류 비교 | 데이터 없는 패널 유지, 연구 수치 미확인 |
| 목표 코스/속마음/궤적 금지 | 미지원·빈 값·가정 라벨 | 타자 행동과 독립 도착 표본, 누수 검사 |
| 부모/자식 재사용 | 데이터/정책/규칙/학습/기록 공통 모듈 | E01 수직 경로 구현, E02는 자료 감사 후 |

실제 자료와 독립 검증이 없으므로 v4의 **연구 가능한 산출물 완료 기준은 아직 충족하지 않았다.** 네트워크/수동 내보내기로 실제 자료가 확보되면 현재 경로에서 보정·검증·학습을 실행한다.
