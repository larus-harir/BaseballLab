# 연구 목적과 개발 단계

목표는 **경기 승리만을 추구하는 AI의 전략 변화**를 관찰하고 인간 야구와 비교하는 것이다.

| 단계 | 현재 상태 | 검증·확장할 내용 |
|---|---|---|
| 부모 기반·M1 | 구현·검증 | 공통 타석 엔진, 설정·정책·기록, 고정 기준선 |
| 전체 경기·M3 첫 버전 | 구현·검증 | 주자·득점·이닝·끝내기·승패, 합성 제구/강도/피로·번트·병살 |
| 신경망 경쟁 학습·M4 첫 버전 | 구현·검증 | 최종 승패 보상, 과거 상대 풀, 고정 조건 평가, 저장 정책 재평가 |
| 관찰·M5 첫 뷰어 | 구현 | 한국어 HTML의 세대별 행동 확률·성적·투구 재생 |
| 실데이터·M2 | 다음 주요 연구 과제 | 소규모 MLB 수집·표준화·품질·확률 보정, 합성 환경에서 나온 전략의 민감도 |
| 경기·학습 고도화 | 후속 실험 | 선수·타순·수비·주루·교체, 다른 알고리즘·여러 학습 seed, 완전한 학습 재시작 |
| E02 | 설계 | KBO 접근·이용 조건/공통 특징, 독립 학습 정책의 공정한 교차 대결 |

마일스톤 번호는 원본 설계서의 구성 요소를 가리킨다. 현재는 실제 리그 자료를 확보하기 전에도 합성 경기에서 승패 보상 학습을 실행하고 전략 변화를 관찰할 수 있다. 실데이터 기반 검증은 별도로 수행한다. 학습이나 보고서가 있다는 사실을 현실 야구에 대한 과학적 결론과 혼동하지 않는다.
