# 연구 목적과 개발 단계

핵심은 사람이 정한 야구 전략을 보상으로 주입하지 않고, **경기 승리만을 목표로 경쟁한 AI의 전략 변화**를 관찰하는 것이다. 각 단계는 다음 단계에 필요한 검증 기반을 제공한다.

| 단계 | 구현·검증할 내용 | 현재 상태 |
|---|---|---|
| M0 부모 기반 | 공통 계약, 자식 실험, 설정·정책 등록과 평가·기록 | 구현·검증 |
| M1 E01 기준선 | 타석 규칙, 합성 결과 모델, 9조합, seed 반복, 행동·투구 기록·리포트 | 구현·검증 |
| M2 데이터 | 소규모 MLB 수집/캐시/표준화/결측·품질, 합성 모델과 비교·보정 | 다음 개발 단계 |
| M3 전체 경기 | 주자·득점·이닝·선후공·경기 종료, 승패와 현실 제약 | 계획 |
| M4 경쟁 학습 | 승패 보상, 타자/투수 학습, 번갈아 학습·self-play, 과거 모델 평가 | 계획 |
| M5 관찰·비교 | 학습 회차별 전략 변화, 인간 야구 기록과 비교·개입 검증 | 계획 |
| M6 E02 | MLB/KBO 독립 학습 정책을 중립·리그별 환경에서 교차 평가 | 데이터 가용성·공정성 설계 |

타석 단위 지표를 경기 승리로 바꾸어 부르지 않는다. 승리 보상을 연결할 전체 경기와 현실 제약을 검증하고, 고정 상대·과거 모델·별도 seed 평가를 통해 자기대결 50%가 숨기는 변화를 관찰한다. 인간 야구와의 유사성은 실제 기록·모델 보정·민감도 분석으로 검증한다.

관련 근거는 [원본 설계서](specs/Baseball_AI_Lab_Master_Handoff.md)의 연구 목적과 마일스톤을 따른다. 이후 개발은 이 흐름과 실험 결과에 맞춰 이어간다.
