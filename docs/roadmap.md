# v4 개발·연구 단계

목표는 경기 승리를 추구하는 AI의 전략 변화와 인간 야구의 비교다. v4는 실제 근거를 연구 실행의 선행 조건으로 둔다.

| 단계 | 현재 구현 상태 | 실제 연구 검증 상태 |
|---|---|---|
| 데이터 감사·계보 | 공식 수집기·수동 내보내기 어댑터·해시·품질·결측·단위 구현 | 공식 페이지 접근 확인, 이용 조건에 따른 공식 CSV 내보내기 확보 필요 |
| 최소 경험 모델 | 기간/경기 분리·빈도·풀링·오차·불확실성·진입 기준 구현 | 실데이터 보정·독립 검증 미실행 |
| 최소 경쟁 학습 | 두 정책 업데이트·과거 풀·기준선·체크포인트·배치별 버전·로그 구현 | 실데이터 연구 학습 보류; 테스트 전용 입력으로 기술 검증 |
| 최소 관찰실 | 스트라이크존·투구 재생·정책/전략·현실 검증·출처 패널 구현 | 실제 데이터 대기 화면 및 테스트용 UI 동작 검증 |
| 승리 목표 확장 | 기존 합성 경기 로직은 단위 테스트에만 보존 | 실제 주루·수비·능력·피로 전이 근거 확보 후 경기 모델로 연결 |
| 견고성·인간 야구 비교 | 설계 | 독립 기간·여러 학습 seed·모델/상대 민감도·역사 지표 정합성 |
| E02 | 설계 | KBO 공식 자료 접근·이용 조건과 특징 가용성 감사 후 공정한 교차 대결 |

실데이터가 확보되기 전 결과 미확인을 실패로 숨기거나 합성 성과로 대체하지 않는다. 제한된 타석 보상을 경기 승리로 표현하지 않으며, 관측 분포의 재현을 반사실 인과 타당성의 증명으로 부르지 않는다.

웹 실행실을 추가했다. 화면에서 데이터 확인·모델 검사·학습 시작·진행/중지·결과 열기를 수행하며, 연구 타당성의 검사를 건너뛰는 버튼은 제공하지 않는다.
