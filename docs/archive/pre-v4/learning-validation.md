마지막 이닝 2점 뒤진 동일 상황의 타자 행동 확률은 컨택 약 21.7%→47.8%, 번트 약 23.8%→12.2%로 변했다. 무사 1루 동점에서는 컨택 약 18.9%→36.6%로 변했다. 이 변화를 보상이나 정답으로 지정하지 않았다. **모든 상대에서 개선된 것은 아니며, 한 학습 seed의 결과로 전략의 우월성이나 실제 야구의 결론을 주장하지 않는다.**

생성된 [한국어 대화형 보고서 샘플](learning-sample.html)을 브라우저에서 열면 세대별 확률·고정 상대 성적·경기 재생을 볼 수 있다. 이 파일은 커밋 전 작업 트리의 실제 실행 결과이고 코드 SHA256과 환경 버전이 함께 들어 있다. 전체 모델과 원본 실행 이력은 outputs/에 저장하며 Git에서는 제외한다.
