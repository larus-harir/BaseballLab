# 실제 타구·투구 기록 확인 · 2026-11-11

새 관찰 기능은 보관한 공식 Retrosheet CSV의 미사용 필드를 읽습니다. 가상 대결에 속도·좌표를 덧붙이는 기능이 아닙니다. 원본·기존 정제본·학습 결과는 변경하지 않습니다.

| 실제 정규시즌 기록 | 2023 | 2024 |
|---|---:|---:|
| 기록 날짜 | 03-30~10-01 | 03-20~09-30 |
| 완료 타석 | 184,104 | 182,449 |
| 원천 `bip=1` 완료 타석 | 118,373 | 118,758 |
| 타구 종류 미확인 | 0 | 0 |
| 타구 위치 코드 미확인 | 16 | 9 |
| 첫 처리 수비 위치 미확인 | 0 | 0 |
| 투구 결과 코드열 없는 완료 타석 | 0 | 0 |
| 전체 홈런 / `bip=1`에 포함된 홈런 | 5,868 / 7 | 5,453 / 8 |

`bip=1`의 홈런은 실제 사건 코드에 `/IPHR`가 있는 장내 홈런입니다. 따라서 이 타구 표본을 **모든 타구**로 부르면 안 됩니다. 전체·범위 내·범위 밖 홈런 수를 별도로 반환합니다. 투구 코드열이 있다는 것은 구종·속도·좌표가 모두 있다는 뜻이 아닙니다.

확인 가능한 것은 `hittype`의 땅볼/뜬공/팝업/직선타/번트 종류, `loc`의 원래 타구 위치 코드, `firstf`의 첫 처리 수비 위치, `pitches`의 투구 결과 순서입니다. `firstf=8`은 중견수가 먼저 처리했다는 의미이지 착탄 좌표가 아닙니다. `loc`의 `+` 접미는 2023년 115,061타석, 2024년 115,192타석에 있으며 이번에 확인한 열 정의만으로 그 접미의 뜻을 확정하지 못했습니다. 그대로 보존하며 각도·미터·구장상의 점으로 변환하지 않습니다.

공식 투구 코드의 B/C/S/F/X는 볼/루킹 스트라이크/헛스윙 스트라이크/파울/인플레이입니다. 자동 판정 A/V, 투구 없음 N, 견제 1/2/3, 주석 `+ * . >`는 별도로 구분합니다. 문자 수를 실제 투구 수로 세지 않으며 모르는 기호는 원문과 ‘미분류 코드’를 남깁니다.

현재 원천에는 **타구 속도·발사각·측정 구속·구종·홈플레이트 통과 좌표·비행 궤적이 없습니다.** 이 값은 평균이나 수비수 번호로 채우지 않습니다. Statcast가 해당 센서 필드를 제공하지만 현재 앱은 실제 센서 CSV를 확보하지 않았고, 기존 MLB 자동 수집 제한을 우회하지 않았습니다.

## 2025 공식 자료를 실제로 추가 수집

공식 고지의 허용 문구·2025 다운로드 링크를 확인하고, 기존 자료와 다른 비공개 후보 폴더에 원본 ZIP·CSV·고지·획득 시각·검사 manifest를 새로 보관했습니다. [공식 2025 배포](https://www.retrosheet.org/downloads/plays/2025plays.zip)의 SHA256은 `ea7f4be3464825b332ed6f8c19e15310858458ea9eddf3e91a954e5b47f69d73`, 추출 CSV는 `2c58a5ceeae9b653dddc8b4d20fa9b3810bfd3a6d40c29786509c5e060a5f23f`입니다. 원본과 로컬 경로는 Git에 넣지 않습니다.

후보에는 2025-03-18~09-28 정규시즌의 **189,939플레이·182,926완료타석·119,245 BIP타석**이 있습니다. 전체 CSV 193,767행 중 비정규/비완전 기록 3,828행을 검사 집계에서 제외했습니다. BIP 위치 코드 결측은 9개, 투구 코드열이 없는 완료 타석은 0개입니다.

기존 제공자와 같은 32MiB 다운로드·256MiB 추출 한도에서 단일 정상 CSV 멤버·경로·암호화/링크 부재·CRC·필수열·2025 날짜·완료 타석 ID 중복 0·14개 타석 사건의 배타성을 확인했습니다. 상태는 **후보 원본 수집·스키마 검사 완료**이며 **학습 등록은 하지 않았습니다.** 정제 전이 순서·모형 보정·독립 예측 검사는 아직 수행하지 않았으므로, 검증된 2023/2024 학습이나 화면 시즌에 몰래 섞지 않습니다.

Git 갱신 후 개발자가 같은 고정 배포를 수집하는 명령은 `python scripts/collect_retrosheet_candidate.py`입니다. 필요하면 `--root <저장소 루트>`를 지정합니다. 임의 URL·연도는 받지 않고, 매번 새 비공개 후보 폴더를 생성하며 ZIP·CSV 지문이 위 검토본과 다르면 중단합니다. 이 명령은 일반 학습의 자동 자료 준비 경로와 분리되어 있습니다.

읽기 전용 인터페이스: `baseball_lab.data.contact_observations.observations(root, season, batter_id)`. 시즌 전체·투수 관측은 `summarize(root, season, role=None)` / `role='pitcher', player_id=...`로 읽습니다. 첫 요청은 검증된 시즌을 한 번 집계하고 이후 같은 원천 해시의 인덱스를 재사용합니다. 다운로드·수정·모형 보정은 하지 않습니다. 완료 타석 중복·선수 식별자 결측은 집계를 중단합니다. 타구 종류별 합계+미확인은 `bip=1` 타석 수와 같으며 모든 자료는 원천 해시·범위·결측 수와 함께 반환합니다.
