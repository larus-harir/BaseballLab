# 다음 Match 전술 실험의 계약

선정: **같은 아웃·주자 상황에서 수비의 정상 승부/고의볼넷 선택을 통제 비교**합니다. 이미 구현된 R1의 행동·규칙·실제 자료를 재사용하는 후속 설계입니다. 이번 변경에서 이 실험을 새로 학습·완료했다고 발표하지 않습니다.

| 항목 | 다음 실행에서 고정할 내용 |
|---|---|
| 질문 | 같은 공격 상대·출발 상태에서 고의볼넷 선택 변화가 이 제한된 환경의 실점 방어 성과에 어떻게 연결되는가? |
| 관측 | 행동 전 공개 아웃 수와 1·2·3루 점유. 상대의 숨은 행동·미래 타석 결과·사후 타구 정보 제외 |
| 행동 | 수비: 정상 승부/고의볼넷. 공격: 우선 번트 없는 공격으로 고정해 수비 선택 효과를 분리. 이후 상대 적응은 별도 비교 |
| 보상 | 기존과 같은 세 아웃 전 한 점 득점/저지. 9이닝 승리·투구 제구 학습이 아님 |
| 규칙/환경 | 기존 `r1.environment`의 강제 진루 규칙과 실제 관측 플레이 묶음. 공격 고정 조건, 지지 표본, 128턴 중단 원인을 기록 |
| 자료 | 공통 `DatasetCatalog.ensure('match', season)`의 실제 Retrosheet 2023/2024. 기존 원본·검증된 정제 ID 유지 |
| 기간 | 실제 관측 날짜·중단 경기 처리와 경기 단위 분리를 별도 감사. 기존 연구 결과를 다시 쓰지 않고 새 실행에만 적용 |
| 평가 | 같은 상대·같은 난수 쌍에서 상태별 득점/차단·고의볼넷 빈도·선택 확률을 구분. 실제 출발 빈도와 균등 24상태 시작을 별도 표로 비교 |
| 반복 | 최소 3개 학습 난수, 고정/과거 상대, 독립 시즌, 조건별 작은 표본·분산·관측 선택 편향을 함께 보고 |
| 기각/완료 조건 | 동률 기준 50%로 우열 판정 금지. 행동 변화만으로 개선 판정 금지. 표본 없는 행동·미관측 투구 변수를 생성하지 않음 |

고의볼넷의 강제 진루는 규칙으로 정의할 수 있지만, 이후 상대 타석 결과와 사람의 선택에는 선수·상황 선택 편향이 남습니다. 이를 현실 감독 전술의 인과 효과로 발표하지 않습니다.

## 투구 연구로 확장할 때 필요한 입력

| 필요한 정보 | 지금 상태 | 확보 후 검사 |
|---|---|---|
| 투구 전 카운트·주자·아웃·공개 구종 이력 | 플레이 문자열 일부는 있지만 의도한 구종/코스의 행동 계약과 다름 | 사전/사후 필드 분리, 시간 순서·상대 정보 누수 검사 |
| 실제 구종·구속·도착 위치·타구 정보 | 현재 R1/시즌 카탈로그에 없음 | 허용된 상세 자료·단위·센서 결측·공급원 정의 대조 |
| 투수가 의도한 코스·타자가 노린 구종·선구안 | 직접 관측하지 못함 | 관측 위치를 의도로 치환하지 않고 잠재변수/가정 범위를 명시 |
| 같은 상황에서 고르지 않은 행동의 결과 | 직접 관측 불가 | 지지 범위·선택 편향·민감도·행동 조건부 결과 모델을 독립 검증 |

현대 야구 비교는 우선 정의가 일치하는 **3개 시즌**을 목표로 하되 현재 공식 등록은 2023/2024 두 시즌입니다. 세 번째 시즌은 제공원·스키마·이용 고지를 검토하기 전 지원한다고 표시하지 않습니다. 장기간 역사 변화는 규칙·측정·선수 구성 차이를 통제할 별도 Match 연구 축입니다. EraMatch의 역대 선수 가상 대결과 합치지 않습니다.
