## 어떻게 변했나?

같은 최종 확인 환경에서 시점별 공격 득점률은 **학습 전 69.3% → 1,000상황 50.1% → 2,000상황 47.5% → 3,000상황 46.9%**였습니다. 수비 차단률은 각 값의 보완값입니다. 같은 고정 상대에 대한 개선과 현재 맞대결의 우세를 구분해 표시합니다.
