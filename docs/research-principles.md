# 연구 원칙

최종 학습 목표는 경기 승리입니다. M1에는 보상이나 학습이 없으며 타석 결과를 승률로 바꾸지 않습니다. 적극·인내·스트라이크 우선 등의 휴리스틱은 비교 기준일 뿐 학습 전략의 정답이 아닙니다.

합성 모델의 상성은 실제 야구의 발견이 아닙니다. 학습 이후에도 시뮬레이터의 보정과 민감도, 고정 상대·과거 모델·다른 seed 평가를 거쳐야 합니다. 자기대결 50%로 개선 여부를 판정하지 않습니다. 승률 등 연구 추론에는 다중 seed와 불확실성 보고가 필요하며 현재 단일 seed 결과는 작동 확인입니다.

전체 경기(M3) 이후 승패 보상, M4에서 경쟁 학습을 도입합니다. 관측 누수·불가능한 능력·규칙 허점 검증을 선행합니다. 인간 야구와의 비교는 출처가 검증된 실제 기록과 분리된 보고서에서 수행합니다. 역사와 닮았다는 서술은 가설이며 개입 실험과 데이터 근거가 필요합니다.
