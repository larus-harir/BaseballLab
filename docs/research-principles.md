# v4 연구 원칙

궁극적 목표는 경기 승리다. P1의 제한된 타석 대리보상은 그 이름과 한계를 표시하며 승리 최적화와 구분한다. 실제 자료·모델로 근거가 없는 경기 전이를 연결하지 않는다.

실제 기록으로 결과 모델을 보정하고, 타격·투구 전략의 정답 레이블로 쓰지 않는다. 신경망은 실제 업데이트되어야 한다. 관측 가능한 범위만 행동·상태에 넣고 현재 투구·사후 센서·상대 선택을 미리 주지 않는다.

REAL_OBSERVED / EMPIRICALLY_ESTIMATED / MODEL_SIMULATED / UNVERIFIED_ASSUMPTION / MOCK_TEST_ONLY를 혼용하지 않는다. 모델 재추출은 실측 기록이 아니며, 독립 기간에서 관측 분포를 재현하는 것은 인과효과의 증명이 아니다.

자기대결 50% 대신 고정 상대·과거 모델·여러 seed를 평가하고, 표본 수·구간·실패 셀을 공개한다. 정책 변화는 로그의 측정 사실로, 이유는 검증할 가설로 기록한다. 자료가 없거나 유의미한 결과를 확인하지 못하면 그대로 기록한다.
