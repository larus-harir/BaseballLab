# 데이터와 출처

현재 데이터는 전부 hand-authored `synthetic-v1`입니다. take 판정, 접촉 확률, 인플레이·안타 유형 분포는 시연용 가정입니다. 실제 MLB/KBO 또는 선수 능력을 나타내지 않습니다. 데이터 다운로드와 네트워크 인증은 시뮬레이션에 필요하지 않습니다.

M2 후보는 Baseball Savant/Statcast (https://baseballsavant.mlb.com/csv-docs), pybaseball의 Statcast 지원입니다. 공식 설명·이용 조건·연도별 정의를 확인하고 2024 정규시즌의 작은 기간부터 시작합니다. 원본/캐시/출처/버전/라이선스/가용성/결측 사유/단위/품질표를 저장하고 시간순 검증 분할을 합니다. 미래 투구 결과 컬럼은 정책 관측에서 제외합니다. 2026 존 좌표 정의 등 연도별 변화는 확인 없이 통합하지 않습니다.

KBO는 공식 기록의 접근 가능 범위와 자동 수집·재이용 조건을 별도로 확인해야 합니다. Statcast와 동등한 투구 추적 자료가 있다고 가정하지 않습니다. 공통 최소 특징으로 축소하거나 타석 단위 비교를 고려하며 결측 센서 값을 실제 관측처럼 만들지 않습니다. 이번에는 수집·이용 조건 조사·실제 보정을 수행하지 않았습니다.
