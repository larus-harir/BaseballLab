# v4 검증 기록

실제 CSV 확보는 0건이다. 공식 Statcast 접근은 클라우드 프록시 CONNECT 403으로 차단되었다. 실제 표본 수·결측률·보정 오차·정책 학습 성과는 미확인이다. 합성 자료로 대체하지 않았다.

테스트 98개로 어댑터·해시·기간 분할·경험 확률·도착 위치의 행동 독립성·양쪽 정책 업데이트·재현·재생·차단 경로를 검증했다. 생성 자료는 MOCK_TEST_ONLY이며 연구 성과로 사용하지 않았다.

Chromium에서 테스트 전용 입력으로 스트라이크존·실제/모델 레이어·체크포인트·seed·정책 카운트·검증 구간 전환을 검사했다. 별도로 실제 DATA_REQUIRED 화면에 결과 점이 없음을 확인했다. 브라우저 정책으로 파일 URL 대신 로컬 HTML을 독립 오프라인 페이지에 렌더링했다. 캡처는 outputs/E01/v4-source-status/data-required.png에 생성했다.

공식 도메인 허용이 적용되거나 공식 CSV 내보내기를 가져오면 보정·독립 검증을 수행하고, 통과한 범위에서 실제 연구 학습을 진행한다. 현재 모델은 명시된 타석 출루 대리보상을 사용하는 제한된 PoC이며 경기 승리 연구 완료를 의미하지 않는다.
