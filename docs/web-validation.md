# 웹 실행실과 타당성 검토 검증

## 이번에 구현한 것

기본 실행은 로컬 웹 연구실이다. 공식 CSV 업로드·출처 기록·검사 날짜 설정·검사 작업·학습 시작·진행·중지·기록·중간/최종 결과 열기를 제공한다. 쉬운 한국어와 단계별 설명을 먼저 표시하고 기술 기록은 접을 수 있게 했다.

## 실제 확인한 범위

- Python 3.12.14 / NumPy 2.5.4 / Linux CPU에서 테스트 **110 passed**.
- 로컬 HTTP의 상태 조회·자료 없는 학습 차단·잘못된 업로드·Host/Origin/토큰·경로 이탈 방지.
- 고정 인수 목록으로 작업 실행, 실제 하위 프로세스 중지·진행 기록, 단일 작업 제한, 서버 재시작 시 중단 상태 처리.
- 전체 비율은 맞지만 조건별 결과가 정반대인 테스트에서 전체 TV=0만으로 통과시켜선 안 됨을 확인. 조건별 가중 TV와 단순 모델 대비 Brier 차이를 추가했다.
- 공식 지표 분모·결측·확률이 아닌 OPS·서로 배타적인 사건의 확률 합 검사.
- Chromium 실제 로컬 HTTP 페이지에서 안내, 접힌 도움말, 잘못된 CSV의 피드백, 검사 전 학습 비활성화, 새로고침, 데스크톱·모바일의 가로 넘침 없음을 확인. 페이지 JavaScript 오류 없음.
- 개발 설치와 wheel 생성 성공, 패키지 안에 웹 실행 화면과 결과 화면 HTML이 들어 있음을 확인.

검사에 사용한 생성 데이터·제어 프로세스는 테스트 전용이다. 실제 자료로 실행한 연구 성과가 아니다. 브라우저에서 실제 자료 없는 상태와 오류 처리를 확인했으며, 실제 Statcast CSV의 성공 업로드→검사→학습을 완료했다고 주장하지 않는다. 연구 학습의 두 정책 갱신은 기존 테스트 전용 입력의 통합 검사로 확인했다.

## 공식 근거와 데이터 상태

허용 설정 적용 뒤 Statcast robots.txt/열 정의와 MLB BABIP·FIP·OBP·이용약관이 HTTP 200으로 열렸다. 이용약관에 자동 스크립트 수집 제한이 있어 기본 경로를 공식 내보내기 후 업로드로 정했다. robots.txt 허용을 수집 권한으로 간주하지 않았다. 별도 허용 근거 없이 자동 수집을 실행하지 않는다.

사용자 제공 과제의 코드·주석·CSV를 읽고 [세이버메트릭스 검토](sabermetrics-review.md)에 판단과 실제 확인 범위를 기록했다. 원본 CSV·학생 식별 자료를 재배포하거나 검증된 KBO 학습 데이터로 채택하지 않았다.

실제 투구 CSV는 이번 작업에서 새로 확보하지 않았다. 실제 모델 적합도·전략 변화·현실 야구의 성능에 대한 연구 결과는 미확인이다.
