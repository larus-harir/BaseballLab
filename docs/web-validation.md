# 웹 실행·실제 연구 검증 · 0.7

공식 Retrosheet CSV 다운로드와 정규화가 실제로 완료됐습니다. 기본 화면에서 **AI 학습 시작**을 눌러 3,000상황 × seed 41/42/43을 실행하고 작업 완료·결과 링크를 확인했습니다. 실제 날짜·표본·오차·정책 결과는 [연구 기록](r1-research.md)과 [집계 실행 근거](results/e01-r1-2024.json)를 보세요.

전체 **129 tests passed**. 기존 단위/HTTP/중지/경로·Origin·토큰 검사를 유지했고, 새로 공식 CSV 변환·끝내기 non-PA 보존·행동 마스크 경사·기간별 환경 분리·두 정책 갱신·체크포인트 재현·반사실 대조 구분을 검사했습니다. 테스트 생성 자료는 MOCK_TEST_ONLY이며 연구 성과로 옮기지 않았습니다.

실제 Chromium으로 기본 Retrosheet 선택·학습 시작·완료·결과 진입·seed/저장 시점/시작 상황 변경·턴 이동·정책 그래프·독립 평가·교차대결을 확인했습니다. JavaScript 오류가 없었습니다. 첫 브라우저 자동 검증에서 완료 대기를 잘못 확인한 스크립트는 실패로 처리했고, 작업 ID를 고정한 상태 조회와 완료 후 실제 상호작용으로 다시 확인했습니다.

[실행실](images/workbench.png) · [실제 실행의 턴 관찰실](images/r1-replay.png)

공식 Retrosheet 경로의 HTTPS 200과 배포 이용 고지를 직접 확인했습니다. Statcast CSV 설명의 재요청은 HTTP 403이었으며, 기존 MLB 약관의 자동 스크립트 수집 제한도 별개입니다. Retrosheet 접속 성공을 Statcast 수집 허용이나 모든 프록시 차단 해소로 보고하지 않습니다.

테스트 통과는 프로그램 동작에 관한 근거입니다. 이번 실제 연구에서도 타격 측 성과 향상은 확인하지 못했고, 번트 관측의 선택 편향·선수/카운트/점수 생략은 해결되지 않았습니다. 전체 경기 승리 학습을 완료했다고 보고하지 않습니다.
