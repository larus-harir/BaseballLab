## 원본과 개선 후보의 차이

| 항목 | 과제 재현 | 개선 비교 후보 |
|---|---|---|
| 팀 분할 | 기준(타자 200PA·투수 150TBF)을 만족한 첫 행 | 같은 ID·시즌의 서로 다른 팀 행 합산. 불명확한 중복은 차단 |
| 사건 | 삼진·볼넷·홈런 이항 결합 후 BIP와 타자 안타 구성 추첨 | K/BB/HBP/단타/2루타/3루타/HR/기타의 겹치지 않는 전체 분할 |
| 시대 | 원본 통산/시즌 리그 비율 배율 | 전체 사건의 상대 비율 이동 후 정규화. 검증된 공정성은 아님 |
| 표본 | 원본 고정 상수 150/200/300/800 및 투수 150/200/400 | 전체 사건에 같은 가상 표본 강도. KBO 기본 100은 검증 전 설정 |
| 투수 BABIP | 원본대로 리그 평균 강제 | 실제 허용 안타 사건 비율을 포함. 수비·구장 영향이 제거된 순수 능력 아님 |
| 확률 합 | 원본 표시 K+BB+HR가 1 초과 가능. 실제 순서 분기의 실현 확률도 별도 공개 | 사건별 b×p/l의 합으로 나눠 전체 합 1 |
| 결측/타율 | 원본의 SF 결측 0과 순서 추첨은 재현. 원본 PA−BB의 값을 공식 타수/타율로 재표시하지 않음 | 세부 사건 결측은 계산 차단. 실제 AB와 PA 분모를 구분 |

원본 재현은 원본을 과학적으로 승인했다는 뜻이 아닙니다. 원본의 ‘운을 제거한 진짜 실력’, ‘투수에게 BABIP 제어 능력이 없음’, ‘시대 간 공정 대결’ 표현은 입증된 결론으로 채택하지 않았습니다. SABR 다항 Log5와 MLB 지표 정의를 직접 대조했으며 Morey 논문을 검증 완료했다고 주장하지 않습니다.

`python scripts/validate_assignment.py`는 해시가 고정된 검토 원본의 클래스만 분리해 simulate를 호출합니다. import·main·원본 파일 로딩은 실행하지 않습니다. 실제 선수 조합 40쌍+테스트 전용 극단 2쌍×난수 5개 = **210개 조건**에서 25타석 사건별 개수가 정확히 일치했고 원본 출력 확률도 반올림 오차 내 일치했습니다. 코드/ZIP/자료 지문은 [재현 기록](results/assignment-reproduction.json)에 있습니다. 이 비교는 원본의 통계적 정확도를 검증하지 않습니다.

## 자료와 권한

MLB는 기존 공식 공급원을 공유하고 이름도 공식 로스터를 선수 ID로 연결했습니다. 다운로드 URL·원본 SHA·수집 시각·이용 고지를 보존합니다. 과제 KBO는 **LEGACY_UNVERIFIED**이며 원천 Kaggle URL·버전·재배포 권한·HP/BB/IB 정의를 독립 확인하지 못했습니다. 일부 과거 투수의 피2루타/피3루타가 없으면 개선 비교를 막고 원본 경로의 지원 여부만 보여줍니다.

`data/local/catalog/` 아래 카탈로그/원본, `outputs/workbench/` 아래 각 실행의 확률·선수·모델·코드 지문·난수·반복·저장 보고서가 있습니다. Git에는 원본 ZIP/CSV/Python/PDF·체크포인트를 배포하지 않습니다. 새 PC에서 MLB는 자동 준비 버튼, EraMatch는 사용자가 보관한 원본 ZIP의 최초 연결이 필요합니다. 자료가 없으면 허구 선수·자동 성공을 만들지 않습니다. [출처 상세](data-sources.md), [보안 범위](security-audit.md).
