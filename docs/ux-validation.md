# 사용자 화면·자료 보호 실행 검증 · 2026-11-05

## 사용자가 달라진 점 5개

1. 홈의 버튼을 **야구 장면 보기 / 실험 설정하기**로 바꿔 실제 동작과 이름을 맞췄습니다. 아직 준비 중인 한 타석 연구의 새 학습 버튼은 비활성으로 표시합니다.
2. 관람은 작은 주자 표 대신 **2D 야구장·아웃 표시·이번 장면 득점·사건 카드·장면 목록**으로 구성했습니다. 실제 관측과 가상 장면을 계속 구분하고 재생·일시정지·속도·이전/다음을 제공합니다. 없는 궤적·구속·전체 점수는 그리지 않습니다.
3. 결과 첫 결론을 **득점 704/1,500**으로 고쳤습니다. 이전 ‘수비 우세’는 철회했습니다. 공격/수비가 맡은 과제가 비대칭이므로 50%가 능력의 동등 기준이라는 근거가 없습니다. 같은 상대를 상대한 학습 전후 개선은 별도로 유지합니다.
4. **같은 야구 상황과 학습 시점**을 골라 선택 확률·실제 누적 선택 횟수·별도 평가 성적을 구별하고, 같은 출발 장면의 학습 전/선택 시점을 나란히 볼 수 있습니다. 저장하지 않은 장면은 없다고 표시합니다.
5. **자료와 신뢰성**이 실제 보관 항목·용량·분류·검사·관련 연구를 보여줍니다. 삭제는 대상과 영향을 먼저 보고 다시 동의해야 실행합니다. 실험 중 정리는 막고, 기존 자료는 자동으로 지우지 않습니다.

## 실제 사용과 캡처

Chromium으로 홈 → 연구 설정 → 실제 학습 → 선택 변화·같은 상황 비교 → 저장 장면 → 원본 검사 → 삭제 미리보기 취소를 실행했습니다. 가상 관람과 실제 원천 관람을 모두 열고 재생/일시정지·속도·이전/다음·장면 이동을 확인했습니다. 실제 작업 중지와 다른 탭의 중복 시작 차단, 모바일 가로 넘침 없음과 Tab 키 조작도 확인했습니다. 최종 화면에 JavaScript 오류가 없었습니다.

첫 브라우저 검사에서 누락된 아웃 표시 요소 때문에 단계 화면 초기화가 멈춰 수정했습니다. 별도로 브라우저 자동화의 문자열 eval 대기가 새 CSP에 차단돼, 보안을 풀지 않고 DOM 대기로 검사 스크립트를 고쳤습니다. 실패한 검사를 통과로 처리하지 않았습니다.

첫 방문자의 질문(실제/가상, 지원하는 선택, 학습 목표, 다음 동작)을 기준으로 자동 사용 시나리오를 검토했습니다. 별도 사람 대상 사용성 실험이나 화면읽기 전문 시험을 완료했다고 주장하지 않습니다.

## 실제 연구와 보존

공식 2024년 보관본으로 **3,000번씩 3회** 학습했습니다. 작업 ID는 `20261105_062831_10dfe156`입니다. seed별 학습 이력·최종/초기 평가·체크포인트 교차대결이 기존 2024년 실행과 일치했습니다. 2024년에 저장한 정책을 **재학습 없이 2023년**에 확인하는 평가도 다시 실행했습니다.

기존 원본·정제 기록·저장 모델 **85파일**의 실행 전후 SHA256이 같았습니다. 기존 HTML/JSON은 웹에서 읽어 새 화면으로 만들 뿐 덮어쓰지 않는 회귀 검사를 통과했습니다. 데이터·신경망·보상은 바꾸지 않았고 해석·표시·저장 보호를 수정했습니다. 연구 실행 시 코드 hash/dirty 상태는 해당 research.json에 그대로 기록하며, 이후 표시용 보호 수정까지 그때 실행됐다고 소급해서 쓰지 않습니다.

집계 결과: 공격 득점 704/1,500(46.9%), 차단 796/1,500(53.1%). 같은 고정 상대에 대한 수비 차단률은 28.9% → 52.1%, 공격 득점률은 45.9% → 45.7%입니다. 선택 변화와 동반된 결과이며 인과적 원인을 확정하지 않습니다. 관측 선택 편향·상황 생략·표본 제한은 여전히 남습니다.

## 보안·검증 범위
