# 첨부 과제의 세이버메트릭스 논리 검토

PDF 보고서와 ZIP의 Python 코드(특히 주석), 타자·투수 CSV를 읽고 아래처럼 판단했다. 사용자의 연구 아이디어 참고 자료이며, 검증된 KBO 원천·현실 예측 모델로 간주하지 않는다. 원본 파일과 개인 식별 정보는 저장소에 재배포하지 않는다.

## 실제 확인한 자료 구조

첨부 ZIP SHA256: `57ab8411a07b901206b0af798d9f55a00cab79ea1d61adac492e86571b2a1058`.

타자 CSV는 1982~2025년 9,731행, 투수 CSV는 7,727행이었다. 보고서에 Kaggle 이용이 적혀 있지만 원본 URL·버전·수집 조건을 독립 확인하지 못했다. 연구 데이터로 채택하지 않았다.

타자 자료에는 HP 열이 모든 행에 있었고 SF 결측은 없었다. 9,560행은 `PA = AB + BB + HP + SH + SF`가 맞았다. 나머지 차이는 다른 타석 종류·정의·데이터 오류 가능성이 있어 원천을 확인해야 한다. HP를 사구로 대응할 수 있는지 공식 정의를 확인해야 하며, 코드 주석의 ‘사구 데이터 없음’은 먼저 재검토해야 한다.

같은 선수 ID·연도 키의 추가 행이 206개 있었다. 살펴본 예는 같은 해 팀이 바뀐 분할 기록이었다. `iloc[0]`로 첫 행만 선택하면 시즌 기록 일부를 놓칠 수 있다. 전체 합산 행이 중복 포함됐는지도 확인한 뒤 리그 합계를 내야 한다. 동일 선수 시즌의 합산 여부는 팀별 분할과 합계 행의 의미를 확인한 후 결정한다.

## 유지할 관점 / 그대로 쓰지 않을 가정

| 논점 | 검토 | 반영 |
|---|---|---|
| 작은 표본의 평균 회귀 | 합리적인 통계적 도구지만 운을 ‘제거’하거나 순수 실력을 확정하지 못함 | 표본 N·불확실성·독립 검증 유지. 고정 상수는 미채택 |
| 안정화 상수 150/200/300/800 | 주석의 저자·문헌·지표 정의·표본 단위와 해당 수치를 독립 확인하지 못함 | 타 리그/시대에 그대로 적용하지 않음 |
| 시대 보정 | 리그 환경을 구분하려는 접근은 타당한 질문 | 모든 시대를 통합한 비율로 나눈다고 구장·장비·선수 구성까지 중립화되지는 않음 |
| DIPS와 투수 BABIP 고정 | 공식 MLB 설명은 투수의 약한 타구 유도 능력도 BABIP에 영향을 준다고 명시 | ‘투수의 제어 능력은 없다’ 또는 강제 평균 고정을 채택하지 않음 |
| BABIP | `(H-HR)/(AB-K-HR+SF)`는 공식 정의와 일치 | SF를 모르는데 0으로 채우지 않음. 분모·결측·기간 표시 |
| Log5 결합 | 코드 식은 사건 odds를 리그 odds로 조정하는 형태 | K/BB/HR를 각각 결합해도 배타적 결과의 합이 1이라는 보장은 없음. 현실 맞대결 효과 검증도 별도 필요 |
| 확률 합 >1에서 BIP=max(0, 나머지) | 난수 분기의 앞 사건이 뒤 사건의 실현을 막아 제시 확률과 달라질 수 있음 | 유효한 결합 분포 검사를 추가하고 오류를 숨기지 않음 |
| 타율의 타수=PA-BB | 사구·희생타 등이 없는 제한 모델에서는 쓸 수 있으나 공식 타수와 일반적으로 다름 | 공식 통계로 표기하지 않음 |
| 25타석 난수 결과 | 모델의 한 표본일 뿐 타당성을 입증하지 않음 | 예측·현실·가상 결과와 오차를 분리 |

새 `evaluation/sabermetrics.py`는 AVG/OBP/SLG/OPS/BABIP/K%/BB%의 분자·분모·결측 사유를 반환한다. HP는 원천 정의 없이 HBP로 자동 변환하지 않는다. 지표는 관찰용이며 현재 AI의 보상이나 선수 능력 계산에 주입하지 않는다. 기존 과제의 예측기를 포팅한 것이 아니다.

## 직접 확인한 공식 근거

2026-11-04에 다음 공식 페이지를 HTTPS 200 응답으로 읽었다. 정의의 확인이며 우리 시뮬레이터의 현실 타당성 인증은 아니다.

- [MLB BABIP](https://www.mlb.com/glossary/advanced-stats/babip): 공식 식 및 투수/타자의 타구 질·기량 영향 설명. ‘모든 투수 BABIP가 동일’ 가정을 지지하지 않는다.
- [MLB FIP](https://www.mlb.com/glossary/advanced-stats/fielding-independent-pitching): K·BB·HBP·HR, 이닝과 FIP 상수를 사용. BIP를 제외하는 지표 설계이지 투수의 BIP 영향이 정확히 0이라는 증명은 아니다.
- [MLB OBP](https://www.mlb.com/glossary/standard-stats/on-base-percentage): 안타·볼넷·사구 출루 포함, 실책·선택수비 출루 제외. 우리 타석 대리보상과 다르다.
- [Statcast 열 정의](https://baseballsavant.mlb.com/csv-docs): plate_x/z가 2026년부터 ABS에 맞춘 middle-of-plate로 바뀌고 sz_top/bot의 정의도 달라짐. 연도별 자료를 무비판적으로 통합하지 않는다.
- [MLB 이용약관](https://www.mlb.com/official-information/terms-of-use): user conduct 항목에서 자동 스크립트 수집 제한 문구를 확인. robots.txt의 접근 허용이 약관상 수집·재배포 허가를 뜻하지 않는다.

특정 안정화 상수, 시대 중립화, Log5의 리그 간 전이 효과는 이번 자료만으로 검증하지 못했다. 이후 검토할 후보이며 검증된 현행 결과 모델로 사용하지 않는다.
