# 기존 웹 동선의 단계적 개선 · UI 검토

기준: 2026-11-11, 기존 `web/matchup.html`과 서버 렌더 경로를 그대로 사용했습니다. 별도 앱·새 루트·복제 확률 엔진을 만들지 않았습니다.

## 증상 → 원인 → 수정

| 증상 | 원인 | 기존 코드에서 바꾼 동작 |
|---|---|---|
| 모델·재현 번호를 알아야 대결할 수 있음 | 연구 설정과 일반 선택이 같은 깊이에 노출 | 기본은 리그·시즌·이름·타석 수·‘대결 시작’. 모델은 자동 선택, 설정은 ‘계산 방식·재현 설정 더 보기’로 이동 |
| 자료 준비 버튼을 먼저 찾아야 함 | 자료 상태와 실행 흐름이 분리 | 프로젝트/MLB 시즌 선택 시 등록된 기록을 자동 확인·준비하고 실제 작업 메시지를 표시. 실패할 때만 재시도 버튼 제공 |
| 과제 ZIP을 반복해서 연결해야 한다고 느껴짐 | 연결/재사용 상태 설명 부족 | 연결한 KBO 기록은 그대로 사용. 원본이 없는 환경만 최초 ZIP 연결 안내 표시 |
| 결과 표가 먼저 나와 결론을 읽기 어려움 | 모든 사건·반복 범위가 기본 화면에 펼쳐짐 | 결과 한 문장·4개 카드·한 타석 재생을 먼저 제공. 전체 확률·반복 범위는 접힌 상세로 보존 |
| 타석을 버튼 목록에서만 볼 수 있음 | 저장 사건의 재생 제어 부재 | 실제 저장된 사건 배열을 이전/다음/자동 재생/번호 입력으로 이동. 주자·아웃·구종을 새로 꾸미지 않음 |
| 다른 시즌을 빠르게 고르면 선택이 꼬일 수 있음 | 비동기 응답과 양쪽 검색의 세대 관리 혼용 | MLB는 두 선수 시즌을 함께 변경, Era는 해당 쪽 검색만 갱신. 오래된 응답은 버리고, 계산 중 조건을 바꾸면 과거 결과를 새 선택 위에 덮지 않음 |
| ‘기록 확인’이 최신 네트워크 자료라는 인상을 줌 | 보관 파일 검사와 원본 수집 시점 구별 부족 | 실제 해시/캐시 확인 시점을 ‘보관본 확인’으로 표시. 네트워크 최신화나 과학적 검증 인증을 주장하지 않음 |

홈과 기존 진입점의 이동 메뉴는 ‘선수 대결 / AI 전략 연구 / 역대 선수 대결’로 맞췄습니다. 기존 `/simulation`, Match의 학습·기존 결과·자료 관리 경로는 유지했습니다.

## 계산 설명·출처 유지

오른쪽 패널은 현재 선택한 이름과 시즌, 원본 기록, 표본/시대 보정, 실제 계산 중간값, 가정과 예측 검사로 연결됩니다. 일반 설명은 짧게 두고 표·식·식별자·원본 해시는 접어두었습니다. 자동 선택된 실제 계산 방식·한글 검증 상태·선택 이유를 보여주며, 공통 실행 계약의 엔진 버전·표본 분모·한계도 상세에 표시합니다. 이전 저장 결과에 새 필드가 없어도 기존 필드로 재열립니다.

KBO의 과제 재현/개선 후보, 실제 관측 기록/추정 확률/가상 추첨은 구분합니다. 25타석을 9이닝 점수나 공식 타율로 바꾸지 않습니다. MLB 2023 선택에서 2024 문구가 남지 않도록 시즌은 응답과 현재 선택을 따릅니다.

## 직접 확인한 UI

- JavaScript 구문: HTML의 실제 inline 스크립트를 추출해 `node --check` 통과.
- 기존 실제 `analysis.json`을 새 렌더러로 열어 Chromium 1366×950, 390×844에서 저장 결과 표시 확인.
- 이전/다음 타석, 자동 재생/일시정지, 키보드 번호 이동, 마지막 타석 다음 버튼 비활성, 확률 상세 펼침 확인.
- 위 저장 결과 시나리오에서 JavaScript 오류 0개, 모바일 가로 넘침 없음.
- 관리 브라우저는 `file://` 열기를 차단했으므로 같은 화면을 임시 로컬 HTTP 서버로 검사했습니다. CSP의 `unsafe-eval`은 추가하지 않았습니다.
- 실제 통합 API로 MLB 2024 기본 자동 계산, MLB 2023 선택/두 선수 시즌 동기화/자동 계산, Era 1982·2024의 빠른 양쪽 연도 변경 후 계산을 Chromium에서 끝까지 확인했고 JavaScript 오류는 0개였습니다.
- 데이터 자동 준비·빈 설치·오프라인 실패·복구·기존 Match의 전체 시나리오는 별도 QA 브라우저와 최종 통합 보고의 결과를 따릅니다.

명시적인 label, 오류 alert/초점, 키보드 제어, 초점 윤곽과 재생 상태를 제공합니다. 실제 화면읽기 프로그램과 사람 대상 사용성·접근성 인증, Windows 권한·암호화는 검사했다고 주장하지 않습니다.

최종 통합 검토에서 2023 보정값 설명도 수정했습니다. 일반 설명과 펼친 예측 검사에서 2024 검증값 300 고정·2023 재선택 없음·회고 검사를 구분하며, 실제 2023 대결 후 두 문구를 브라우저에서 확인했습니다.
