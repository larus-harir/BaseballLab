# Codex 작업 변경 요청 — 실제 기록 기반 E01 + 시각화 요구사항

**반드시 먼저** `Baseball_AI_Lab_PROJECT_VISION_v4.md`와 `Baseball_AI_Lab_VISUAL_REAL_DATA_SPEC.md`를 읽어라. 기존 `Master_Handoff`, `Start_Prompt`, `Vision_v3` 또는 이전 수정 내용과 충돌 시 **v4 우선**이다.

## 내가 추가하고 싶은 핵심 조건

내 프로젝트는 타자 AI와 투수 AI가 오로지 승리를 위해 서로 경쟁하며 어떤 야구 전략을 새로 발전시키는지 관찰하고, 그 결과를 실제 인간 야구의 역사·현대와 비교하는 연구다. E01은 이를 위한 첫 번째 자식 실험이고, 부모 Baseball AI Lab은 이후 MLB vs KBO 등 다양한 실험이 가능한 공통 플랫폼이다.

**(1) 화면에서 경기와 전략의 진화를 눈으로 이해하고 싶다.** 숫자만 보는 통계판이 아니라 스트라이크존, 볼카운트/주자/아웃, 구종·투구 위치, 타자의 선택, 결과, 투수의 재대응을 한 공씩 따라갈 수 있는 시뮬레이션 리플레이를 원한다. 학습 체크포인트를 바꾸면서 타자·투수가 어떤 행동을 더/덜 선택하게 되는지 그래프로 보고, 실제 MLB 관측 분포와 시뮬레이션 분포도 비교할 수 있어야 한다. 가능한 경우 타구 방향/수비를 추가하되 근거 없는 3D 궤적을 만들지 말라.

**(2) E01의 야구 정보, 통계, 확률, 선수 능력치는 실제 데이터를 근거로 해야 한다.** 개발자가 임의로 만든 구속, 타율, 타격 성공률, 구종 구사 비율, 물리 효과 등을 실제 기반 모델인 것처럼 사용하지 말라. MLB Statcast/Retrosheet 등 출처가 확인되는 자료로 우선 최소 범위를 확보해 보정·검증하라. KBO는 실제 확보 가능한 공식 기록부터 감사하고, 없는 데이터를 지어내지 말라. 개발 전용 mock은 단위 테스트에 한정하며 연구 결과와 혼용하지 않는다.

**(3) 시뮬레이션은 실제 경기 기록 자체가 아니라 실제 데이터로 검증된 모델의 생성 결과라는 점을 표시하라.** 모든 데이터·화면에 `REAL_OBSERVED`, `EMPIRICALLY_ESTIMATED`, `MODEL_SIMULATED`, `UNVERIFIED_ASSUMPTION`, `MOCK_TEST_ONLY` 상태를 구분하고, 데이터 출처/조회기간/N/가정/모델 버전/실험 ID를 추적할 수 있게 설계하라. 이용 불가한 기록은 '데이터 없음' 또는 '미지원'으로 표시하라.

**(4) AI가 모를 정보를 아는 것처럼 주지 말라.** 결과 이전에 상대의 선택·구종/목표 코스나 사후 지표를 완전히 아는 AI가 되어서는 안 된다. 실제 투구 도착 위치는 실제 투수가 의도했던 목표 코스와 같지 않다. 인간 선수의 속마음도 Statcast에서 곧바로 알 수 없다. 선택되지 않은 행동의 결과는 데이터만으로 확인할 수 없으니 별도 모델 가정·검증이 필요하다.

## 작업 절차

1. 현재 코드에서 근거 없는 임의 확률/능력/플레이 결과 생성, 누수, 가짜 기록 UI, 진짜 로그와 연결되지 않은 차트가 있는지 파일 단위로 확인하라. `실측 근거 있음 / 통계 추정 / 가정 / mock / 미구현`으로 분류하라.
2. 기존 부모·E01 아키텍처를 가능한 유지하되, 데이터 출처와 모델 버전을 기록하는 계보 구조를 추가하라.
3. 범위를 최소화해서라도 우선 **실제 Statcast 데이터 입수 → 스키마/결측 검사 → 관측 분포 기반 최소 모델 → 독립 검증**을 가능하게 하라. 실제 데이터 확보 실패 시 연구 실행을 보류하고 이유를 보고하라.
4. 타자·투수 AI를 실제로 학습시키고, 선택/결과/상대 체크포인트 변화를 로그로 저장하라. 승률뿐 아니라 전략 변화가 보이는 지표를 남겨라.
5. 그 실제 실행 로그에 연결되는 **최소 시각화 세트**를 만들어라: (a) 스트라이크존 + 한 구 리플레이, (b) 학습 체크포인트별 타자·투수 전략 변화, (c) 실제 관측과 시뮬레이터 검증 결과의 비교.
6. 실행 가능한 명령과 테스트 결과, 데이터 출처, 재현 조건, 화면 캡처/경로, 아직 구현하지 못한 부분을 알려라. **실험하지 않은 숫자는 생성하지 말라.**

내가 가장 중요하게 생각하는 건 화려한 게임 화면이나 임의로 잘 맞춘 숫자가 아니라, **실제 야구에 근거한 환경에서 AI들이 스스로 선택하며 발전하는 과정을 시각적으로 관찰하고 검증하는 것**이다.
