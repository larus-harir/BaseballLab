# E02 MLB-trained vs KBO-trained (설계만)

서로 다른 리그 데이터로 독립 학습한 정책을 같은 공통 환경에서 대결시킨다. E01의 엔진/정책 계약/프로파일/평가/추적 코드를 재사용하며 엔진을 복제하지 않는다.

필요한 선행 작업:

- MLB/KBO 자료의 합법적 접근·재이용 조건, 해상도·결측·연도·단위 확인 및 독립 어댑터.
- 공통 관측/행동 스키마와 명시적 변환기. 비호환 체크포인트는 로딩 시 거부.
- 같은 학습 예산, 고정 기준선·과거 모델, 3개 이상 seed, 동일 평가 seed 목록.
- 중립 규칙·동일 선수 능력·동일 관측을 기본으로 리그 내부 및 양방향 교차 대결. 전체 경기에서는 선후공·타순도 교환.
- 중립/MLB/KBO 보정 환경별 재평가와 동일 능력/리그별 능력 실험을 분리해 정책과 환경 영향을 구분.

KBO 투구 추적 자료가 없으면 양쪽 공통 특징을 축소하거나 타석 수준 실험을 먼저 한다. 실제 자료 없는 합성 KBO-inspired 모델은 실제 KBO-trained AI로 부르지 않는다. 이번에 수집·학습·교차 대결은 구현하지 않았다. 특정 시뮬레이터 정책의 우세를 실제 리그 전력 차이로 해석하지 않는다.
