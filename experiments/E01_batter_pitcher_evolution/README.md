# E01 · 실제 근거 기반 타자·투수 경쟁 학습

프로젝트 헌장 v4를 따른다. 실제 데이터 준비·감사·기간 분리 보정/검증 후에 두 정책의 경쟁 학습을 실행한다. 실행·가져오기 명령은 [부모 README](../../README.md), 알고리즘과 가정은 [학습 설계](../../docs/learning.md)를 참고한다.

현재 P1은 기록에서 확인할 수 있는 카운트·스윙/테이크·구종으로 한정한다. 보상은 명시된 타석 출루 대리변수이며 전체 경기 승리가 아니다. 원래 승리 연구의 목표를 위해 주루·수비·능력·피로의 근거를 확보한 뒤 경기 전이를 확장한다.

한국어 관찰실의 스트라이크존/재생, 전략 변화, 현실 검증은 원천/모델/실행 ID에 연결된다. 실제 자료가 없으면 연구를 보류한다. 이번 클라우드에서 공식 도메인 접근이 프록시 403으로 차단돼 실제 학습 결과는 없다. 이전 합성 샘플은 docs/archive/pre-v4로 이동했으며 연구 근거에서 제외했다.
