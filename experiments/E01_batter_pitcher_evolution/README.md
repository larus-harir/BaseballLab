# E01 Batter vs Pitcher Evolution

연구 가설: 경쟁 학습에서 카운트별 스윙·구종 선택 등이 자발적으로 변화하는가? 인간 야구와의 유사성이 학습 결과인지 시뮬레이터 편향인지 검증한다.

M1에서는 학습 이전의 기준선을 마련한다. `configs/m1_baseline.json`의 seed, 타석 수, 타자·투수 목록, 프로파일·규칙을 사용한다. 공통 엔진을 호출하는 `run.py`는 `python scripts/quickstart.py --config <path> --output <directory>`로 실행한다.

고정 정책은 랜덤/적극(컨택·파워 반반)/인내(2스트라이크 전 기다림), 랜덤/스트라이크 우선(존 패스트볼)/혼합(구종 균등, 존 목표 65%)이다. 타자에게 현재 구종과 코스를 주지 않는다. 타석 결과, 행동·구종·위치·카운트별 횟수, 행동·구종 선택률, 초구 스윙률 및 초구 스트라이크율을 기록한다. 초구 스트라이크는 strike/foul만 센다. 인플레이는 포함하지 않으며 이 정의를 실제 리그 지표와 혼동하지 않는다.

합성 모델, 독립 타석, 동질 능력, 단일 seed의 시연이다. 승패·득점·진화·실제 리그 성능은 측정하지 않는다. 다음 순서는 M2 데이터 검증/보정, M3 전체 경기, M4 승리 보상과 경쟁 학습이다.
