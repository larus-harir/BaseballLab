# E01 · 타자·투수 경쟁 진화 연구

질문: 경기 승리만으로 경쟁 학습한 타자·투수가 어떤 상황에서 어떤 야구를 선택하게 되는가? 전략의 변화는 인간 야구와 닮는가, 시뮬레이터의 편향을 공략하는가?

```powershell
python -m pip install -e ".[learning]"
python scripts/quickstart.py --open
```

기본 실행은 3이닝 경기 600번의 실제 신경망 정책경사 학습이다. 타자 4행동·투수 18행동, 공개 경기 상태, 경기 승패 보상, 과거 상대 풀과 기준선을 사용한다. 중간 지표를 보상하지 않는다. 한국어 report.html에서 고정 상대 성적·상황별 선택 변화·평가 경기 재생을 확인한다. [학습 설계](../../docs/learning.md)에 알고리즘과 경기 가정을 기록했다.

단축 경기는 연구 초기의 짧은 의사결정 환경이다. `--innings 9 --games 5000`처럼 전체 경기 길이와 학습 예산을 바꿀 수 있다. 타순/선수 교체·수비·주루 정책은 후속 확장이다. 원래 M1의 고정 기준선 타석 실험은 `--mode baseline`으로 실행한다.

E01의 실행 입구는 공통 CLI에 연결하며 실제 학습·경기·결과 확률·평가·체크포인트·HTML 기록은 부모 모듈을 호출한다. 실제 MLB/KBO 데이터 보정·교차 비교는 별도 데이터 검증과 E02 조건에 따라 이어간다.
