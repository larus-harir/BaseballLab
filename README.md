# Baseball AI Lab · 야구 AI 연구실

**경기 승리를 추구하는 AI가 어떤 야구 전략을 발전시키는지 관찰하는 연구 플랫폼**입니다. 공통 엔진·자료·학습·기록 위에 첫 자식 실험 E01을 개발합니다.

## 실행하기

Python 3.11 이상을 설치한 뒤, 저장소 폴더의 PowerShell에서 실행하세요.

```powershell
git pull origin main
python -m pip install -e ".[learning]"
python scripts/quickstart.py --open
```

웹에서 **AI 학습 시작**을 누르세요. 기본 기간은 2024년 정규시즌입니다. 공식 Retrosheet 자료 다운로드 → 실제 기록 검사 → 기간 분리 → 두 AI 학습 → 결과 보기를 자동으로 진행합니다. 직접 CSV를 찾거나 올릴 필요가 없습니다. 최초 실행은 인터넷이 필요하고, 다음부터는 체크섬을 확인한 보관 자료를 재사용합니다. CPU로 동작합니다.

화면이 안 열리면 브라우저에서 `http://127.0.0.1:8765`를 여세요. 실행 중에는 터미널을 열어 두고, 종료하려면 Ctrl+C를 누르세요. 포트가 사용 중이면 `--port 8766`을 붙이세요.

## 지금 실제로 무엇을 배우나요?

**E01-R1: 세 아웃 전에 한 점 이상 득점하기 / 이를 막기.** 출루 자체에 보상하지 않습니다. 타격 측·투구 측의 두 작은 신경망이 마지막 득점 성공·실패만으로 가중치를 갱신합니다.

- 타격 측: 일반 타석 / 번트 시도가 포함된 타석. 해당 아웃·주자 상황의 실제 표본이 부족하면 번트 선택을 닫습니다.
- 투구 측: 정상 승부 / 고의볼넷. 고의볼넷은 실제 기록으로 확인한 강제 진루 규칙을 사용합니다.
- 관측: 선택 전 아웃·주자 상태. 상대의 현재 선택이나 미래 결과를 먼저 보지 않습니다.
- 결과: 같은 상황의 실제 플레이 전이를 재추출합니다. 임의 성공률·선수 능력치·피로 효과를 넣지 않습니다.

**전체 경기 승리 AI의 완성은 아닙니다.** Retrosheet에 없는 구종·코스·구속이나 스윙 의도를 만들어내지 않습니다. 선수의 세밀한 동작보다 거친 팀 측 선택을 다루는 첫 득점 상황 실험입니다. 번트 관측은 무작위 실험이 아니므로 선수·상황에 따른 선택 편향이 남아 있습니다. 여기서 좋아진 전략을 현실 야구의 최적 전략으로 해석하면 안 됩니다.

## 결과에서 확인할 것

- 학습 시점별 같은 상황의 행동 확률과 실제 신경망 갱신 기록
- 저장 시점·seed별 턴 리플레이: 선택 전후 아웃·주자, 행동, 득점, 원천 플레이 ID
- 고정·초기·과거·사람의 관측 빈도 상대 평가와 체크포인트 교차대결
- 여러 seed, 평가 표본 수와 오차 구간, 독립 기간에서 모델과 실제 기록의 분포 차이
- 번트 전이를 일반 타석 전이로 바꾼 대조 실험: 관측 행동 구분에 결과가 얼마나 의존하는지 확인

각 seed의 기본 학습량은 3,000상황입니다. 번호 3개로 반복하며, 오래 학습한다고 항상 성적이 좋아지는 것은 아닙니다. 모든 아웃·주자 상황을 같은 비중으로 시작하므로 표시되는 득점률은 실제 경기 승률이 아닙니다.

## 자료와 신뢰성

공식 [Retrosheet 배포·열 정의·이용 고지](https://www.retrosheet.org/downloads/plays.html)를 확인하고, 공식 2024년 플레이 CSV를 사용합니다. 원본 ZIP·CSV·이용 고지와 SHA256을 로컬에 보존합니다. 모델을 만드는 기간, 학습 중 검사 기간, 학습 종료 후 최종 확인 기간은 경기 단위로 겹치지 않게 나눕니다. 실제 관측·추정·AI 가상 결과·미검증 가정을 구분합니다.

자료는 `data/local/retrosheet/official-2024/`, 실행 결과는 `outputs/workbench/`에 저장합니다. 원본·학습 파일은 공개 Git에 올리지 않습니다. 웹은 개인 PC의 `127.0.0.1`에서만 열립니다. 기존 Statcast 출루 실험은 별도 선택지로 유지하며, 공식 사이트에 접속된다는 사실만으로 자동 수집 허가를 가정하지 않습니다.
