# Baseball AI Lab · 야구 AI 연구실

**AI가 야구를 어떻게 배우고 전략을 바꾸는지, 믿을 수 있는 근거와 함께 관찰하는 프로젝트**입니다. 공통 플랫폼 위에 타자·투수 경쟁 연구인 E01을 개발하고 있습니다.

## 시작하기

Python 3.11 이상이 필요합니다. 저장소 폴더의 PowerShell에서 실행하세요.

```powershell
git pull origin main
python -m pip install -e ".[learning]"
python scripts/quickstart.py --open
```

브라우저에 **야구 AI 연구실**이 열립니다. 이후에는 화면의 버튼으로 진행합니다. 브라우저가 열리지 않으면 주소창에 `http://127.0.0.1:8765`를 입력하세요. 터미널은 실행 중인 채로 두고, 종료할 때 **Ctrl+C**를 누르세요. 포트가 사용 중이면 `--port 8766`으로 바꿀 수 있습니다.

## 화면에서는 이렇게 진행하세요

1. **자료 준비:** 공식 Statcast 검색에서 상세 투구 CSV를 내보내고, 웹 화면에서 파일·검색 주소·획득 시각·이용 조건 메모를 올립니다. 처음에는 2024년 5월 1~6일 정규시즌처럼 짧은 기간을 권합니다.
2. **모델 검사:** 화면의 기본 날짜는 앞선 3일로 모델을 만들고, 다음 1일로 검사하고, 마지막 2일로 독립 확인합니다. 본인의 CSV 기간과 맞춰 주세요. ‘모델 만들고 검사하기’를 누릅니다.
3. **학습:** 검사를 통과하면 ‘학습 시작’ 버튼이 활성화됩니다. 처음에는 기본 600타석으로 확인하세요.
4. **관찰:** 진행 상황에서 완료한 학습 타석과 기록을 보고, ‘결과 보기’를 눌러 투구 재생·상황별 선택 확률·전략 변화·실제 기록과의 차이를 확인합니다. 필요하면 중지하고 새 실험을 시작할 수 있습니다.

**화면이 열리는 것과 연구 준비가 끝나는 것은 다릅니다.** 실제 자료나 검증이 부족하면 학습을 시작하지 않습니다. 그럴듯한 가짜 수치를 채우거나, 학습이 항상 좋아진다고 표시하지 않습니다.

## 지금 무엇을 학습하나요?

타자는 **스윙 / 기다리기**, 투수는 **구종 선택**을 하는 작은 신경망을 학습합니다. 현재 목표는 한 타석에서 **출루하기 / 출루 막기**입니다. 경기 전체의 승리를 배우는 단계는 아직 아닙니다. 현재 성공률도 공식 출루율(OBP) 통계와 다릅니다.

최종 연구 목표는 경기 승리를 추구하는 AI의 전략 변화를 인간 야구와 비교하는 것입니다. 그 전에 주루·수비·득점·피로·선수 능력의 모델이 합당한지 검증해야 합니다. 임의 수치를 더해 완성된 야구라고 부르지 않습니다.

## 가장 중요한 기준: 이 실험은 합당한가?

- 실제 기록과 출처를 확인합니다. 결측은 0이나 평균으로 채우지 않습니다.
- 모델을 만든 기록과 검사할 기록을 분리합니다.
- 전체 평균뿐 아니라 구종·카운트별 오차, 단순 기준 모델과의 차이를 확인합니다.
- 관측 기록, 추정 확률, 모델이 만든 가상 플레이를 구분합니다.
- 기록으로 확인할 수 없는 사람의 의도나 반사실 결과를 사실로 단정하지 않습니다.
- 통계 지표는 관찰용입니다. 특정 스타일이 정답이 되도록 보상하지 않습니다.

첨부해 주신 세이버메트릭스 과제는 코드 주석과 CSV 구조까지 검토했습니다. 평균 회귀·시대 구분·명확한 분모라는 관점은 참고하되, 고정 안정화 상수·투수 BABIP 고정·독립 Log5 확률의 결합은 그대로 채택하지 않았습니다. [검토한 내용과 공식 근거](docs/sabermetrics-review.md)를 보세요.

## 데이터와 보관

공식 사이트 접근은 현재 환경에서 정상 확인했습니다. 다만 MLB 이용약관에 자동 스크립트 수집 제한 문구가 있어 **기본은 공식 CSV 내보내기 후 업로드**입니다. 원본을 공개 저장소에 재배포하지 않습니다. 시즌 합계 자료나 출처가 확인되지 않은 KBO 자료로 투구 단위 모델을 대신 만들지 않습니다.

웹 연구실은 개인 PC의 `127.0.0.1`에서만 실행됩니다. 올린 CSV는 해당 PC의 `data/local/statcast/`, 작업 기록·학습·보고서는 `outputs/workbench/`에 저장됩니다. 다른 사람이 접근하는 공개 서비스로 배포하는 기능은 아닙니다.

이번 작업에서 공식 설명·지표 정의·이용약관은 확인했지만, 새로운 실제 투구 CSV를 수집하거나 실제 데이터 학습 성과를 만들지는 않았습니다. 테스트용 자료의 결과를 연구 성과로 제시하지 않습니다.
